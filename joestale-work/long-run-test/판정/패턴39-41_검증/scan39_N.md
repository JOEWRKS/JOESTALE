# scan39_N (doc_M 1~10장, 39·40·41)

- [40 용어] 제1장 "대대 TOD에 뭐 보입니까?" — TOD가 처음 나오는데 앞서 행동이나 대사로 무엇인지 드러난 적이 없어 독자가 짐작하기 어렵다(3장에서 TOD 사각이 나오지만 1장 시점엔 설명 없음).
- [41 이유] 제1장 "젊은 애들 중에 탄피 세는 놈은 서 중사 하나야." — 같은 장에서 소대가 "탄피 회수하고 정시에 수량 보고"를 시키고 탄피 수 불일치는 조사 대상인데, 젊은 사수가 탄피를 안 센다는 관행 진술이 설정(회수 의무)과 어긋난다. 2장에서 다른 초소는 7~8발씩 올려 보낸다는 말과도 충돌.
- [40 용어] 제9장 "전환 확정, K5, 사전 동의서." — 설정 파일의 지식 ID(K5)가 본문에 그대로 들어왔고, "전환 확정"도 설명 없이 나온다.
