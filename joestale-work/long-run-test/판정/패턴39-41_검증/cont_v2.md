# 1장 v1 -> v2 사실 변경과 2~10장 영향 점검

## 1단계: v2가 사실 수준에서 바꾼 것 (14건)
1. 투시경 순회 주기 명시: v1은 "열 시 정각의 한 바퀴"만, v2는 "두 시간에 한 번"(10시, 다음은 자정).
2. 민규가 쓴 횟수: v1 "한 바퀴밖에" -> v2 "열 시 거 한 바퀴 돌리고 껐다. 다음은 자정".
3. AA 두 개로 여섯 밤: v2는 계산에 랜턴까지 포함("랜턴까지 나눠 쓰면"). 랜턴 배터리는 v1 "같은 AA" -> v2 "투시경 몫".
4. 무전기 배터리 규칙: v1 "여덟 개 따로, 밤새는 못 켜, 정시 교신 때만" -> v2 "한 달 여덟 개, 밤새 켜면 열흘에 바닥, 매시 정각에 소대 부를 때만 켬, 하나 빼면 월말 전에 무전이 죽음".
5. 사격 보고 시점 표현: "정시를 기다리지 않았다" -> "정각을 기다리지 않았다".
6. 50m 표지판 = 교전규칙이 쏘라고 정한 선(신규 설정).
7. 용어: 보고서는 "감염체", 초소에서는 "손님"(신규 설정).
8. 사격 권한 제지: v1 "쏘는 건 사수야. 넌 그거나 세" -> v2 민규 멜빵 고리 소리 후 "손 치워. 쏘는 건 사수 하나야. 넌 거리나 불러". 민규 역할이 "세기"에서 "거리 부르기"로.
9. 지연 판단 근거: v2는 "총성이 길어질수록 소리 난 자리를 찾아오고, 쏜 탄은 전부 이번 달 보고에 오른다"를 명시. 도현 대사 "아직 머리가 안 보여. 기다려."
10. T-박스 보강: "가슴에 탄이 박혀도 손님은 서지 않았다"(신규 사실).
11. 소대 응답 신설: "217 수신. 탄피 세 개, 주워서 자정 교신 때 수 불러. 아침 보고 때 안 맞으면 조사다."(v1은 도현 속생각 "1발 1탄피, 수 다르면 조사"). 소대가 자정 교신 때 수를 부르라고 미리 지시.
12. 태석 대사: "열 발 쐈으면 여기까지 줄 서서 왔어"(신규), 보고 후 무전기를 끔. 넷은 "표지판 안쪽으로 넘어오는 것은 없었다"(v1 "쉰 걸음 안으로").
13. 태석의 놀림 요지: v1 "그거 세는 유일한 놈" -> v2 "탄피야 다들 줍지, 머리 맞춰 눕혀 놓는 놈은 너 하나"(눕혀 정렬하는 버릇이 특이점). 개머리판은 v1 서술(도현만 폄) -> v2 태석 지적 대사로 바뀌었으나 도현이 펴 쓴다는 사실은 동일.
14. 자정 교신 때 태석의 동작: 스위치 두 번 두드림 -> "한 박자 늦게" 무전기를 다시 입에 댐. 장면 끝 상태(탄피 판자 위 2개, 쏜 것 3발, 교대까지 6시간, 소대장 책상까지 8시간)는 불변.

변화 없음 확인: 호칭(도현->"오 형", 민규->도현 "서 중사님/중사님", 태석->도현 "서 중사", 태석->민규 "민규야", 민규->태석 "형"), 영하 8도, 8일/스물세 밤/여섯 밤, 표지판 50m, 3발 3정지, 탄피 3개 중 2개 회수, 넷이 300m에서 돌아섬.

## 2단계: 2~10장 영향
- 1. 투시경 두 시간 주기 -> 영향 없음. 제3장 "새벽 두 시의 한 바퀴", "네 시의 한 바퀴", 제2장 "자정 치를 당겨 썼습니다"와 맞음.
- 2. 열 시 한 바퀴 후 껐다 -> 영향 없음.
- 3. AA 두 개를 랜턴과 공유 -> 영향 없음. 제3장 태석 랜턴, 제4장 "AA 몫을 아끼는 어둠"과 맞음. 제5장 "투시경 몫 두 개가 내일 밤이면 끝나고, 일요일 밤은 맨눈"은 날짜 계산(8일 기준 여섯 밤 = 13일 밤까지, 제5장은 12일 금요일)과 일치.
- 4. 무전기 규칙 -> 영향 없음. 제2장 지훈 "무전기 몫 건드리지 말고요", 제3장 "무전기 스위치는 꺼져 있었다", "무전 켜면 소대가 먼저 물어봐", 제7장 밤 10시 뒤 "한 시간 뒤 정시 교신"(매시 정각과 호환).
- 5. 정각 표현 -> 영향 없음.
- 6. 50m 교전규칙 선 -> 영향 없음. 2~10장에 거리 규칙 인용 없음. 제6장 "100m"는 미군 표적 거리.
- 7. 감염체/손님 용어 -> 영향 없음. 제2장 보고서 "정지 3", 제3장 "손님이냐", 제4장 말장난 "너는 손님이지"와 맞음.
- 8. 사격 권한, 민규 역할 -> 영향 없음. 제2장 민규가 사수 자리를 넘보는 동기(가산 배급)와 오히려 호응.
- 9. 총성 길어지면 더 온다, 탄은 월 보고 -> 영향 없음. 제2장 "이번 달 3발", 제6장 "한 달 면담 기준 10발"/"소리 나는 쪽으로 고개를 돌리는 것"과 맞음.
- 10. T-박스, 가슴 피격에도 안 섬 -> 영향 없음. 제6장 "무릎을 끊어요, 기어 와"와 충돌 없음.
- 11. 소대의 "자정 교신 때 수 불러" 지시 -> 영향 없음. 제1장 자정 교신에서 "회수 중, 아침 보고 때 맞춰" 답, 제2장 세 번째 탄피를 새벽 다섯 시에 찾아 아침 보고에 3발 제출과 맞음. (제2장에 자정 교신 때 못 부른 일의 언급은 없으나 모순은 아님.) 제10장 "탄피를 또 잃어버렸대요"와도 모순 없음.
- 12. 열 발 쐈으면 줄 서서 왔다, 넷 안쪽 불침 -> 영향 없음. 제2장 일지 "고가 밑에 넷, 돌아섬", 대대 TOD "둔치로 안 나왔답니다"와 맞음.
- 13. 눕혀 정렬 버릇의 특이점 -> 영향 없음. 제2장 "초소에서는 눕혀 놓고 세던 것을 소대장 앞에서는 머리를 위로 세워"와 맞음.
- 14. 자정 교신 동작 변경, 장면 끝 상태 불변 -> 영향 없음. 제2장 시작(새벽 다섯 시 세 번째 탄피, 밤샘)으로 자연스럽게 이어짐.

## 요약
바뀐 사실 14건, 어긋남 0건.
