# scan39_T_ch01_v1

- [39 문답] "오 형, 무전기 쪽 것 하나만 돌려 쓰면 안 돼요?" → "같은 AA야. 무전기 몫은 여덟 개 따로 나오는데 그래도 밤새는 못 켜." — 돌려 쓰자는 물음에 "같은 AA"는 오히려 돌려 써도 된다는 쪽으로 읽히고, 안 되는 이유(무전기 몫은 정시 교신용)는 뒷문장에서야 겨우 나온다. 직답이 아님.
- [40 용어] "서 중사님, 사수 자리에서 보여요? 손님 셋, 하계역 쪽." — "손님"이 감염체를 가리키는 은어임을 이 자리에서 짐작할 단서가 없다(뒤 "손님의 다리는 그렇게 굳었고"가 되어서야 간접 추정).
- [41 이유] "지금 쏘면 빗나간 탄이 얼음에 박히고, 그 총성을 듣고 둔치 너머의 것들이 고개를 돌릴 터였다." — 50m에서 쏴도 총성은 같고 실제로 고가 밑 넷이 돌아선다. 80m 사격이 불리한 중간 고리(빗맞음 → 발수 증가 → 총성 누적)가 빠져 이유가 성립하지 않는다.
- [41 이유] "하여간 서 중사는 젊은 애들 중에 그거 세는 유일한 놈이다." — 같은 장에서 탄피 1발 1개 회수·수 확인이 의무(수가 다르면 조사, 소대가 무전으로 확인)로 나오는데, 젊은 쪽 중 세는 사람이 도현뿐이라는 관행 진술이 이 제도와 어긋난다.
