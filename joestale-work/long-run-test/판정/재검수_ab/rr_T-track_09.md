## 2단계: 본문 검수 (reviewer-prompt.md 본문 검수 블록, 체크리스트 1~38)

입력: 본문 `final_T-track_09.txt`, 설계서 `design_T-track_09.json`, 앞 장 맥락 = 위 JSON.
표기: `(앞 장 대조)`는 1~8장 본문·앞 장 맥락을 대조해서 잡은 지적. 문제 줄 끝의 `확신`은 상·중·하.

### 지적 (항목 번호 순)

- [1] "침상 발치의 볼펜이 차트 위에서 한참 움직이지 않았다." — 문제: 바로 앞에서 "군화 소리가 멀어졌다. 커튼이 열렸고"로 행위자가 없어, 볼펜 든 사람이 정우로도 읽힘. 확신 중 — 수정: "유진의"를 넣거나, 소리로 바꿔 "볼펜 소리가 한참 나지 않았다".
- [2] "승선하면 함교부터 잡는다. 선원은 전원 갑판으로. 선장 먼저 묻고, 손 보이는 사람부터 센다. 문 뒤에 선 사람은 문이 열릴 때까지 없는 사람이다." — 문제: 과거형 서술 속에 현재형이 섞이고 따옴표가 없어, 입 밖에 낸 말인지 속생각인지 불명(바로 뒤 유진은 "그다음요?"라고 되묻는다). 확신 중 — 수정: 대사로 따옴표 처리하거나 "~잡았다/~없는 사람이었다"로 시제를 맞춘다.
- [3] "해열제 말고 다른 약은 없느냐고 물으려 했는데 혀가 입 안에 붙어 있었다." (앞 장 대조) — 문제: 8장 어디에도 약 이름이 없고 바로 앞 문장도 "약을 한 번 먹으라고"뿐이라 '해열제'라는 말이 어디서 왔는지 불명. 확신 중 — 수정: 유진 대사에 "해열제 드릴게요" 한 마디를 앞에 두거나 "약 말고"로 줄인다.
- [3] "그 틈에 사람 목소리가 들렸다." — 문제: "그 틈"이 형광등 소리 사이인지 밤 전체의 틈인지 모호. 확신 하 — 수정: "형광등 소리가 끊긴 사이에".

- [10] "쓴맛이 입천장에 남았다" / "입천장이 갈라져 혀끝에 걸렸다" / "그 갈라진 자리를 혀로 누르면서" / "입천장을 혀로 눌렀다" / "입천장이 갈라지는데도 말은 나갔다" — 문제: 입천장 갈라짐이라는 같은 상태를 다섯 번 반복. 확신 상 — 수정: 낮 문단("입천장이 갈라져~")과 16시 선택 자리("입천장을 혀로 눌렀다") 둘만 남기고 나머지 셋을 지운다.
