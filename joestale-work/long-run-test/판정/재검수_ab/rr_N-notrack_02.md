- [35] "민규가 젖은 장갑을 비틀어 물을 짰다." / "젖은 장갑에서 물이 한 방울 떨어졌다." — 문제: 난로 앞에서 말리던 장갑이 몇 분 뒤에도 물이 떨어질 만큼 젖어 있고, 왜 끼지 않고 들고 다니는지(영하 아침) 연유가 없다. 같은 사물이 세 번 감정 표지로 쓰인다. — 수정: 장갑을 말라 가는 상태로 두고 비틀기 동작을 지우거나, 끼지 않은 이유를 앞에 둔다.
