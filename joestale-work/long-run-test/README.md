# (0-2) 장편 일관성 테스트 — 본문 1권 1~10장 (2026-11-04)

질문: 매 화를 쓰면서 앞 화·설정·개요와 모순이 없게 유지할 수 있는가. **추적 파일이 있으면 모순이 줄어드는가.**

## 고정 입력

`joestale-work/long-plan-input/` (동결 2026-11-03). 세계관 8 · 인물 4 · 개요 3 · 세부 개요 1권 1~10장 · design.json(planning). 집필 세션은 이 폴더를 읽기만 한다.

## 두 조건 (같은 모델 Opus 5.5, 같은 입력, 새 세션)

| 조건 | 폴더 | 절차 |
|---|---|---|
| T 추적 유 | `T-track/` | 장마다 joestale D 유형 1~5단계. 쓰기 전에 `tracking.json`을 읽어 설계서에 반영하고, 쓴 뒤 `tracking.json`을 갱신(아래 형식). |
| N 추적 무 | `N-notrack/` | 장마다 joestale D 유형 1~5단계. 앞 장 본문과 고정 입력만 읽는다. 추적 파일 없음. |

장 길이 3,000~4,500자(공백 포함). 세부 개요의 항목(핵심 사건·관건 선택·금지 공개·5단·결미 훅·설계 재료)을 설계서로 옮기고, 대장·배경·금지 공개는 고정 입력에서 가져온다. 설정·개요에서 모순을 발견하면 **입력을 고치지 말고** `issues.md`에 적고 본문에서 한쪽을 택한다.

## 추적 파일 `tracking.json` (T 조건)

```json
{
  "chapter_done": 3,
  "clock": {"date": "2029-01-11", "time": "08:00", "pressure": {"A 서명 마감": "01-14 24:00", "B 수복": "…"}},
  "characters": {
    "도현": {"where": "소대 거점", "injury": "없음", "gear": ["K2 구형", "탄창 2", "투시경(AA 1)"], "credits": 0, "knows_new": ["통보서 순번 1"]},
    "민규": {"where": "C-217", "injury": "없음", "gear": [], "knows_new": []}
  },
  "author_truth": ["별지에 민규 이름이 있다(3장 독자 미공개)"],
  "reader_knows": ["도현 순번 1", "탄피 3개 보고"],
  "foreshadow": [{"id": "F01", "what": "별지 한 장", "planted": 2, "paid": null, "status": "open"}],
  "withheld_still": ["K1 해군 경력 세부", "K3"],
  "open_threads": ["민규가 명단에 없는 이유"],
  "last_scene": {"place": "소대 거점 복도", "ends_with": "통보서 봉투를 안주머니에 넣는다"}
}
```

규칙: 장을 쓰기 전 `clock`·`characters.where/injury/gear`·`withheld_still`을 설계서 사실 사슬에 그대로 옮긴다. 쓴 뒤 바뀐 것만 갱신하고 `chapter_done`을 올린다. `author_truth`에 든 것은 본문에서 시점 인물이 말하거나 알 수 없다.

## 측정 (상위 세션, 집필 끝난 뒤)

1. 모순 수: sonnet 블라인드, 두 조건을 X/Y로, 순서 교환 2회. 장마다 설정·개요·세부·앞 장 본문 대비 P1 날짜·P2 지식·P3 공개·P4 복선·P6 수량·34 사슬·36 시점을 센다.
2. 검증기: 장별 최종 PASS 여부, 수식어 비율, 남은 위반.
3. 비용: 세션별 서브에이전트 호출 수·턴 수.
4. 부수: 문장 품질은 이 테스트의 측정 대상이 아니다. 필요하면 T 승자 조건으로 Fable 3장 재집필을 따로 한다.

통과 기준: T의 모순 수가 N의 절반 이하면 추적 파일을 스킬(round5)에 넣는다. 차이가 없으면 추적 파일은 보류하고 검수 쪽을 강화한다.
