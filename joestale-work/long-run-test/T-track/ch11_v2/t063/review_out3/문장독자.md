되풀이되는 버릇:
- '……'로 시작하는 짧은 속말로 장면을 닫거나 걸치는 일이 잦고(예: '……하필.', '……이걸 다 나한테?', '……빨리 나가자.', '……사흘도 안 걸렸네'), 그중 일부는 앞 대사나 행동과 이어지지 않는다.
- "~을 보았다 / 번갈아 보았다" 같은 시선 문장과 "~을 내리지 않았다" 같은 동작 문장이 이유 없이 끼어들어 장면에 하는 일 없이 놓인다.
