# 12장 대본 재작성 뒤 재검(review_out5: 대화 흐름·독백·문장 독자) 처리 — T-069

입력: 처치실 장면을 대본(scripts/처치실.txt)으로 먼저 쓰고 서술을 끼운 판. 대화 흐름 7장면(×1·△6), 독백 7행(×3·△3), 문장 독자 37건(B8·I5).

반영
- 요지를 속말 꼴로 적은 독백 셋 삭제·교체(독백 ×, 흐름, 문장 I): '두 번째다' → '이번엔 안 눕는다지', '다음 달에나 올 사람이다' 삭제, '같은 날, 같은 통' 삭제, '두 바퀴면 끝이네' 삭제(서술이 이미 대비를 세움), '뭐라고 적히나' → '망우동이라고 할 수는 없는데', '또 안 말해 주네'의 '또' 삭제.
- 장면 5(흐름 ×): 세라 설명 사이에 도현의 답("예. 이어져 있습니다")을 넣어 "쭉 가죠?"가 답을 받게, 유진이 "힘 빼세요" 앞에 팔을 잡는 행동.
- 장면 2·3: "그럼 묻겠습니다" → "얼마나 빨리 아무는 겁니까?", 세라의 한 턴을 세라·유진·세라 세 턴으로.
- 장면 6·7: "거기 찍힌" → "띠에 찍힌", 유진 안내를 둘로, 세라의 둘째 물음에 "세라가 덧붙였다".
- 문장 B: "여덟 시간 서고"(간호장교가 알 수 없고 정보 넘김) → "근무 끝나고", "적어 둘게요"를 적는 행동 앞으로, "물어보시면 말씀드려요"(말해 놓고 피함) 삭제, "저 놓아야 해요" → "저 주사 놓아야 해요", '멈췼다' 오기.

기각(본문 안의 근거)
- 문장 B20 "217초소 분이신데, 1회차 때 먼저 보자고 하셨어요": 세라의 "대상자분한테?"에 유진이 누구인지로 답하는 결. 세라의 결미 "초소에 계신다고 했죠"의 근거.
- 문장 B31 "로트 번호요. 같은 날 같은 통에서 나온 묶음": 검수하는 사람이 제 일 용어를 짧게 답하는 말. 직무 설명(처리 규칙 ⑤ 예외).
- 흐름 장면 1 "목요일에요. 초소에서 함석에 베였습니다"가 보고식: 도현의 -습니다 결(characters.speech).
- 문장 19 띠·이음매·구멍이 안 그려짐: 5장·8장에서 깐 사물이고 이 장은 세라가 빈 병을 들고 짚어 보인다. 더 풀면 설명 대사가 된다.
