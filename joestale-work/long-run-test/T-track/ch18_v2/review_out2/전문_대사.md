## 요약

- 지적 수: 20 (× 6줄: #22, #27, #36, #38, #40, #48 / △ 14줄)
- 장면별 사실만 실은 줄 비율
  - 컨테이너 떡국(대사 29줄): 5줄(#14, #20, #22, #25, #27) = 약 17%. 경계 줄 #4·#13 더해도 약 24%. 장면 ×는 아님.
  - 드럼통·결말(대사 23줄): 엄격히 4줄(#36, #38, #40, #48) = 약 17%. 경계 줄(#33, #43, #54) 더하면 7줄 = 약 30%. 셋 중 하나를 넘지 않음(지훈의 안내 일을 면제로 보면 더 낮음).
  - 단, 사실 줄이 지훈 설명 구간에 몰려 있다.
- 되받기 쌍 수: 4쌍 (#21 방송이요 → #22, #23 여기같이요 → #24, #34 진입조요 → #35 그거요, #37 비운다는 게…겁니까 → #38 그렇죠)
