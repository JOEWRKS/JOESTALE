# 13장 검문 대본 v3 (2회차 반영: 화자·지시어, 민규 '-거든요' 결, 태석이 접는 까닭, 끊김은 말로). 대사·독백만.
# 자리: C-217 옆 접경 도로. 드럼통 둘. 민규(드럼통), 태석(초소 컨테이너 문턱, 일지), 도현. 한 시 십 분.

민규: 그 차 올 때 됐네요. 하루도 안 빠지네, 저 차.
      (흰 탑차. 창이 반쯤 내려오고 서류철. 마스크 안에서 인사가 뭉개진다)
      (차 번호, 봉인 줄 번호, 수거처 칸: 대대 거점·격리반, 처리장 칸: 구리 소각장)
도현: 가세요.
      (돌아서서)
도현: 오 형, 통과요.
      (태석이 문턱에서 시계를 본다)
태석: 13시 20분.
      (탑차가 드럼통 사이를 지나 둑길을 내려간다. 사거리, 오른쪽 깜빡이)
민규: 어, 또 저리 가네.

민규: 택배 때 저 길 3년을 돌았거든요. 저 번호판, 망우동 쪽으로 간 적이 없어요.
태석: 우리 일은 시각 적는 거까지야. 민규야, 드럼통 제자리에 놔.
민규: ……이번 주 내내 저리로 갔어요.
      (민규가 입을 닫고 드럼통을 제자리로 민다)
