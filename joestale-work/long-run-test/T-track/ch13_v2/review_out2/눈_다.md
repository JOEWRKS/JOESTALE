- [11] "홈마다 기름기가 묻어났다." — 문제: 기름기는 "손질해 둠(고마움)"과 "손때·관리 안 됨(꺼림)" 양쪽으로 읽히고, 바로 앞 "먼지가 없었다"와 겹쳐 부수 연상이 흐려짐 — 수정: 이 문장을 지우거나 "엄지에 기름이 얇게 묻어났다"처럼 손 감각 하나로 줄인다
- [16] "아는 길을 다 말하지 않는 눈치였다." — 문제: 민규의 속마음(말을 삼킴)을 서술자가 직접 해석해 줌. 이미 "입을 닫고 드럼통을 제자리로 밀었다"로 보임 — 수정: 문장 삭제
- [17] "'서류엔 구리라고 찍혀 있었는데.'" — 문제: 민규의 "소각장은 왼쪽이에요", "저쪽으로 간 적이 없어요", "이번 주 내내요", 수첩의 월요일 로트 번호까지 이미 같은 불일치를 네 번 연상시킴. 속말이 다섯 번째 반복 — 수정: 속말 삭제, 수첩 줄과 민규 대사만 남긴다
- [17] "도현은 어깨의 K2 구형을 내려 그 총이 기대 있던 벽에 세우고 새 총을 들었다. 구형보다 총구 쪽이 가벼웠다." / "구형보다 가벼운 무게가 허벅지에 다르게 앉았다." — 문제: "새 총이 가볍다"를 두 번(여기에 "구형보다 총구가 덜 들렸다", "구형 때보다 앞쪽에 닿았다"까지) 반복. 마지막 문장은 "다르게 앉았다"가 어떤 감정인지도 한 줄로 안 잡힘 — 수정: 149행 "구형보다 총구 쪽이 가벼웠다"를 지우고 결미의 무게 문장만 유지(또는 반대)
- [17] "두 발 채워 가세요. 60발 맞춰야죠." — 문제: "60발"이 이 글 안에서 설명 없는 세부 숫자. 앞 장 관습을 모르면 무엇을 맞추는지 알 수 없음 — 수정: 숫자를 지우고 "탄피 수대로 채워 가세요" 정도로 하거나, 도현이 탄창에 밀어 넣는 행동만 남긴다
- [21] "짐칸 문은 건드리지 않았다." — 문제: 행동을 "~지 않았다"로 서술. 같은 자리에 구체 행동 긍정형이 가능 — 수정: "도현의 손은 서류철에만 있었다." 또는 "짐칸 문고리 앞에서 손을 접었다."
- [21] "지난번에 앉아 있던 먼지가 없었다." — 문제: 상태를 부재로 설명. 구체 사물로 바꿀 수 있음 — 수정: "렌즈 테두리에 천으로 닦은 결이 남아 있었다."
- [21] "아는 길을 다 말하지 않는 눈치였다." — 문제: 부정형으로 인물 상태 서술(위 [16]과 같은 문장) — 수정: [16]대로 삭제하거나, 긍정 행동으로 "민규는 입술을 안쪽으로 말았다."
