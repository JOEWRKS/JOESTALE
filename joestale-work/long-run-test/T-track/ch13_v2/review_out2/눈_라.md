- [13] "지훈이 사격 허가 대장을 들고 따라 나왔다." — 문제: 앞에서 나온 파란 표지 장비 대장과 같은 역할(기록 대장)의 사물이 하나 더 나온다. 뒤의 "지훈이 대장에 숫자를 적었다."가 어느 대장인지도 모호하다. — 수정: 장비 대장 하나로 합쳐 "지훈이 장비 대장을 들고 따라 나왔다."로 쓴다.
- [25] "민규는 입을 닫고 드럼통을 제자리로 밀었다. 아는 길을 다 말하지 않는 눈치였다." — 문제: 동작 뒤에 대사의 속뜻을 설명하는 문장이 붙었고, 긴장이 오르는 대목이다. — 수정: "눈치였다" 문장을 지우고 드럼통 미는 동작 하나만 둔다.
