되풀이되는 버릇:
- 번호·일지·수거반 같은 말을 설명 없이 던지고 "그걸", "그 번호" 같은 지시어로 받아서 무엇을 가리키는지 계속 흐리다(5, 8, 12~17).
- 대사가 앞 말을 되받는 꼴이고(15, 18), 속은 땀·동작 한 줄로 때운다(4, 9, 20).
