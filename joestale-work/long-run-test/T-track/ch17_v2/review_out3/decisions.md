# 17장 마지막 패스(전문 대사·독백·이치·이야기·인물·대화 흐름 + 문장·플랫폼 독자) 처리 — T-081

입력: draft_r2.txt(2,521자 PASS). 대사 ×7 △9(번호 장면 사실 줄 6/13 ×, 되받기 4쌍), 독백 ×1, 이치 △9(× 0), 이야기 줄임 4·줄임+보강 2, 인물 도현 ×1 △1·가을 △2·보급계 ×1, 흐름 ×1(장면 5) △4, 문장 22, 플랫폼 20(뒤로가기 3번 '무슨 번호인지 모르는 대화', 다음 화 '예').
처리 단위: 대본 v4(scripts/야적장.txt) → draft_r3.txt. 번호 장면과 손톱·연락처 장면을 다시 썼다.

반영
- 번호 장면 스무 턴 → 여덟 턴(이야기 3, 대사 ×10·12·14·16·20, 플랫폼 5·9, 흐름 ②): "소대 물건은 저쪽 창고 / 압니다 / 그럼 저한텐 왜요 / 그래서요 / 누가요 / 언제까지요 / 그 말도 들었습니다" 삭제. 유예는 한 줄로 동사를 갖춰("3월 9일까지 건드리지 않겠다는 약속을 받아 왔습니다", 대사 14 '그렇게 받았' ×). 가을의 물음은 "사수님이 왜요"(플랫폼 4의 '왜'를 가을이 묻게).
- '그 번호'가 이 장에서 안 세워짐(플랫폼 3·뒤로가기, 인물 가을 ②, 흐름 ②·⑤, 문장 2·17·19, 대사 8): 도현 첫 줄 "황 사장이 쥐고 있다는 전화번호 일로 왔습니다".
- "9일이 제 피 뽑는 날이에요…"(대사 ×17, 이치 22 달 없음, 플랫폼 5, 문장 6, 흐름 ②) 삭제 — 가을은 제 사정을 먼저 말하지 않는 사람. 전표 접기도 삭제(이야기 3 '장치').
- 독백 '받기나 할까'(독백 ×, 인물 △, 이치 △24, 이야기 4, 플랫폼 6, 문장 9) 삭제. 설계서 monologue 없음으로.
- 지도 장면 질문 사슬(이야기 4, 흐름 ③, 플랫폼 9·10): "몇 동인지는요 / 끝 동입니다 / 왜요" → "동 번호 같은 건 안 적어요?" / "적으면 보고서가 됩니다. 점만 두는 겁니다"(문장 11·흐름 ③ '군에서 나온 종이' ×). 보고 이유는 한 번("서류로 올라가면 통신 쪽에서 이 단지 전파부터 끊는답니다", 문장 12 누가). "이게 뭐예요"를 가을이 먼저(대사 22, 흐름 ③, 문장 8).
- 1.5km를 도현이 먼저(대사 39, 이치 37, 이야기 5, 흐름 ④, 문장 14, 플랫폼 14): "초소에서 북쪽으로 1.5km쯤입니다" → 가을 "여섯 개. 1.5km네요".
- "안 됩니다. 둘 다" 뒤 행동(이야기 4): 도현이 바로 접기 시작 → 가을 "잠깐만요"가 손톱으로 재는 계기(흐름 ④ 계기 없음).
- 문자 한 줄의 자리(대사 42, 이야기 5, 흐름 ④, 문장 15·17, 플랫폼 15): "그 정도면 전화가 가끔 터져요 … 작년 10월에 그 번호로 문자가 한 번 왔으니까요"(가끔 터진다는 말의 까닭으로). "도현은 묻지 않았다" 삭제(문장 16) → 도현의 손이 모서리에서 멎음.
- 건넴 순서(문장 18): 접은 뒤 가을 "저 주시는 거예요?" → "그러려고 복사했습니다. 접은 채로 넣으세요" → 내밂. 수첩·연필은 안주머니로(이치 25).
- 연락처(흐름 ⑤ ×, 인물 가을 ①③, 이야기 6, 플랫폼 16, 문장 19, 대사 45·47): "저만 그런 게 아니에요 / 몇이나 됩니까" 삭제(도현 되묻기 ×) → 지도를 넣고 소매를 내린 뒤 한 줄 "피 뽑는 날 대기실에 저처럼 번호 하나씩 쥔 사람들이 있어요. 연락처 주고받은 게 마흔 명쯤 돼요. 중계동 쪽 번호 있는지 물어볼게요".
- 끝 약속(대사 ×50 패턴 97 ②, 이치 45, 플랫폼 18, 문장 20, 인물 '도현 침묵'): "답이 오면 다음 토요일 이 시간에 여기 있을게요" / 도현 "자리를 또 바꾸겠습니다". 운전병 "아는 분이에요?" 삭제(흐름 ⑥, 이야기 6).
- 보급계(인물 ×): 한 턴 "중사님, 등유하고 부식입니다. 보시고 서명해 주세요", 도현이 수령증과 맞춰 보고 서명(이치 46).
- 마지막 문장(문장 22, 플랫폼 19·20, 이야기 6): "찬 공기가 코끝으로 들어왔고, 안주머니를 누른 손바닥에 수첩만 잡혔다".
- 총 점검 한 문장(플랫폼 1, 이야기 1). 자리 바꿈 서술 둘("저녁 조 사수와 호송 자리를 바꾼 것이었다. 다음 주 비번 하루가 그 값이었다", 문장 1, 이치 5). 소매는 "박스를 나르느라 걷힌"(이치 14). 손수레 "도현 쪽으로 돌려 세웠다. 맨 위 라면 박스가 책상이 됐다"(문장 10). 두 사람 동작 문단 분리(플랫폼 12). "남은 박스를 짐칸에 올리고"(이치 44). "그건 황 사장하고 한 얘기고요. 저한테는 뭘 주실 건데요"(문장 7, 대사 21). 목덜미(문장 3).

기각(사유)
- 인물 도현 × "서술에서 서도현과 중사를 묶으라" → 패턴 97 ③·W34(시점 인물은 소개하지 않음), W31은 시점 인물 호칭 면제(T-080). 설계서에 계급 근거만 보충(이치 3).
- 대사 △3 "'부르던'으로 끝남·'사수님' 대신 인용" → 가을이 그 자리에서 황의 말을 끌어 호칭을 세우는 줄. 호칭 앵커(95 ①)를 대사 안에 두는 유일한 자리. 유지.
- 대사 △4 "이름 대는 move 누락" → 1회차 흐름 ⑧(자기소개 ×)로 지운 것. 설계서 dialogue_plan 쪽을 고침.
- 이치 39 "'가끔'과 넉 달에 한 통" → 가을의 '가끔'은 외곽 일반을 말하고 문자 한 통은 제 번호의 일. 유지.
- 이치 45 "다음 토요일 호송 근거" → 도현의 답("자리를 또 바꾸겠습니다")으로 받음.
- 플랫폼 4·11 "도현의 속 한 줄" → 삼키는 사람. 손이 멎는 자리·"……예"·끝의 손바닥으로. 말할 내용의 기각(T-080 처리 규칙: 말투 지적은 기각 안 함 — 말투 지적은 전부 반영).
- 플랫폼 13 "손톱 여섯 번이 길다" → 두 문장으로 둠(설계 절정의 행동).
- 이야기 2 "가을이 누구인지 한 줄 깔기" → 가을의 첫 대사(창고·황 사장)와 도현의 첫 답(전화번호)이 그 자리. 서술로 소개하지 않음.
- 문장 12·15 수정 예시 → 뜻만 받음('위에서 끊는다', '휴대폰이 터져요' → '전화가 가끔 터져요').
