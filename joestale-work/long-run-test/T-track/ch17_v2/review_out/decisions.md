# 17장 1회차(눈 가~아 + 문장·플랫폼 독자 + 대화 흐름) 처리 — T-081

입력: draft.txt(2,964자 PASS). 눈 가 10·나 4·다 9·라 8·마 1·바 3·사 11·아 5, 문장 36, 플랫폼 30(뒤로가기 4번, 다음 화 '예'), 흐름 17(장면 2·3·5 ×, 1·4·6 △).
처리 단위: 대본 v2(scripts/야적장.txt) → draft_r1.txt. 장면 2·3·5는 대본에서 다시 썼다.

반영(갈래별)
- 자기소개·출처(흐름 ③, 눈 아 56, 플랫폼 9·10): "서도현입니다. 중랑천 초소에 있습니다" 삭제. 가을의 첫 줄에 호칭 앵커를 둠("황 사장이 사수라고 부르던") → 도현의 첫 답이 5장 전제("그날 사장이 번호 얘기를 할 때 옆에 있었습니다"). 뒤의 "어떻게 아세요" 삭제.
- "그럼요"(눈 사 55, 문장 6) → "그럼 뭘 말하러 오셨는데요".
- 좌표 설명 대사(눈 바 50, 눈 아 54, 눈 다 11, 문장 17, 플랫폼 15, 흐름 ④): "여덟 자리 좌표는 보고서에 적는 꼴 … 점은 접으면 그냥 지도고요" → "숫자가 있으면 누가 봐도 군에서 나온 종이입니다" 하나. 전파 끊김은 한 번("안 썼습니다. 올라가면 그 단지 전파를 자른답니다. 소대장한테 들은 말입니다") — 둘째 설명 줄과 "저는 서류에 없다고 썼습니다" 삭제(문장 19·21, 플랫폼 16, 눈 나 41 대상 통일). 출처는 소대장(=지훈, 눈 사 46; 설계서 toward.소대장 보정).
- 지도 펴는 자리(눈 가 22, 눈 나 34, 눈 라 13, 문장 11): 팔레트 → 가을이 핸드카를 돌려 낸 라면 박스 윗면(눈 마 38의 '경계를 푸는 동작'도 이것으로).
- 1.5km가 먼저 안 섬(흐름 ⑤, 문장 23): 도현 "여기입니다. 초소에서 북쬭으로 1.5km쯤 됩니다" → 가을 "이거 얼마짜리 지도예요?" / "1cm가 250m입니다" → 손톱 여섯 → "여섯 개. 1.5km 맞네요".
- "작년 가을에 한 번 왔어요"(눈 다 11, 눈 사 48·55, 문장 25, 플랫폼 19, 흐름 ⑤): "작년 10월에 문자가 한 번 왔어요. 그 뒤로는 없어요". 앞에 도현의 받는 말 "……그 번호로요". "안쪽" → "구역 안쪽으로".
- 연락처로 넘어가는 고리(눈 사 48, 눈 라 13, 문장 30, 플랫폼 24, 흐름 ⑥): "구역 안에 번호 둔 사람이 저만은 아니에요" → 피 뽑는 날 대기실 → 마흔 명쯤 → "물어볼게요. 중계동 쪽 번호 가진 사람 있는지". 채혈·연구소 낱말은 "한 달에 한 번 피 뽑는 날 연구소 대기실"로.
- 보여 주기 → 넘기기(플랫폼 22): 가을 "가져가도 돼요?" / 도현 "그러려고 찍었습니다. 탑차에 타시면 거기서 펴세요"(문장 27 '어느 차').
- 서술자 문장 "누구의 불빛인지 … 말하지 않았다"(눈 나 36, 문장 31, 플랫폼 26) 삭제 → 도현은 멜빵을 쥔 채, 가을은 핸드카를 돌림.
- 인식표 줄(눈 나 34, 눈 다 11, 눈 아 57, 문장 7·8, 플랫폼 11): "가을의 눈이 옷깃 사이로 나온 인식표 줄에 머물렀다. 도현은 줄을 옷깃 안으로 밀어 넣었다". '목이 뻣뻣해지는 것을 두었다' 삭제.
- 시선·몸 지문 덜어내기(눈 라 25 ×5, 눈 다 9·17, 문장 16·26·29·35, 플랫폼 14·21): "눈이 도현의 손을 한 번 보고", "눈이 지도에서 도현으로", "손끝이 식어 갔다", 둘째 "입김이 끊겼다", "전표를 꺼내던 자리", "소매가 손등까지", "수첩 위, 지도가 있던 자리" 삭제. 소매 뒤 "내린 손이 주머니 위에 머물렀다"(눈 다 9).
- 운전병 답(흐름 ①, 문장 2, 플랫폼 2): "저녁 조 사수하고. 다음 주에 내 비번 하루 주기로 했어". 발단에 독백 하나 '받기나 할까'(패턴 96: 황이 보낸 사람으로 볼 상대에게 건네러 가는 사람이 먼저 묻는 것). 가을을 알아보는 자리에 "민규 말대로 토요일 첫 배차였다"(눈 바 44: 어떻게 알았나).
- 보급계 첫 대사(흐름 ② ×) → 서술(등유가 아직 안 나왔으니 기다려 달라고 했다). 끝 "중사님, 서명이요. 두 부요" → "중사님, 수령증에 서명 좀 해 주세요"(눈 사 55, 문장 33). 등유 말통은 "그사이 … 나와"(눈 라 13).
- 문장: "잔 다리"(가 1, 문장 1), "읽고" → "훑고"(문장 4), "포개져" → "모여"(문장 12), 연필 주어(가 1, 문장 13·14), "그 뒤로는요" → "그 뒤로도 봤어요?"(문장 15), 가장자리 숫자(문장 18), 연필 뗌(문장 22), 뒷문을 가을이 내림(가 1, 문장 32), 빈자리 → "가을의 탑차는 줄에서 빠져 있었다"(문장 36), 토막 "다음 주 저녁 조" 풀어 씀. -고요 꼬리 다섯 → 둘("그 사람 셈이고요", "여기서는 말고요").
- 끝(플랫폼 30): 가을 "토요일마다 여기 와요. 이 시간에" 뒤 문이 닫히고, 마지막은 코끝 한 문장.

기각(사유)
- 눈 다 17 "3분 40초 삭제" → 3장 수치 그대로(세 번·3분 40초), 가을이 셀 수 있는 기준. 유지. 눈 다 17 "마흔 명쯤 → 여럿" → F14(회복자 연락처 40여 명) 심는 자리. 유지.
- 문장 5·플랫폼 9 "사수님 → 중사님" → 가을은 계급을 모른다. 호칭은 황이 부르던 '사수'로 가을의 첫 줄에서 묶음(패턴 95 ①은 남의 호칭에 — 여기서는 대사 안 앵커). 뒤의 "사수님 거예요?"는 그 앵커 뒤.
- 문장 23 "손톱 폭이 1km쯤인 지도라서" → 수치가 틀림(1:25,000에서 1cm = 250m). 축척 물음으로 대신.
- 플랫폼 1·5·6·13·18·28 "총 점검·소리·동작 쪼개기" → 총 점검은 domain_rules(호송 사수)의 행동, 손톱 재기는 절정의 행동. 길이만 덜어냄.
- 플랫폼 3·12·20·25·29 "주인공 속" → 삼키는 사람(인물의 결)이라 속말을 보태지 않되, 발단 독백 하나와 "……그 번호로요"로 받는 말을 둠(말할 내용의 기각일 뿐 말투 지적은 반영 — T-080 처리 규칙).
- 눈 바 44 "바꾼 이유를 발단에" → 이유 문장은 짓지 않음(패턴 90). 독백과 "민규 말대로"로 계기만.
- 문장 24 "안쪽 → 기지국 근처" → 뜻이 틀림(구역 안쪽). "구역 안쪽으로"로.
- 문장 31 수정 예시(두 문장으로 풀기) → 문장 자체를 지움.
