# 15장 1회차(눈 가~아 + 문장·플랫폼 독자 + 대화 흐름) 처리 — T-077

입력: draft.txt(3,039자). 지적 가 13, 나 4, 다 20, 라 7, 마 1, 바 7, 사 9, 아 15, 문장 46, 플랫폼 35, 흐름 ○1 △5 ×1.
처리 단위: 대본 v3(scripts/처치실.txt) → draft_r1.txt(2,711자). 유진 대사가 든 단은 전부 다시 썼다.

반영(갈래별)
- 유진의 설명 턴(바 50 ×3, 사 55 ×4, 흐름 2·3·7, 문장 12·17·19·38, 플랫폼 9·13·29): 인식표 교부·입회·날짜 안내를 각각 도현의 되묻기로 쪼갬. 인식표: "이거 받으세요" → "인식표입니까" → "처치자 거예요, 같이 거세요" → "뒷면에 뭐가" → "글자요" → "물린 사람한테 이게 있으면요" → "목부터 봐요, 그게 있으면 처분 양식은 안 꺼내요"(양식 물음의 앞을 세움). 입회: "받으면 어떻게 됩니까" → "끝까지 옆을 지켜야, 확정 나면 반장님하고 같이 들어가요. 입회요". 날짜: "2차는 90일 뒤" → "4월 말입니까" → "29일이요 … 첫 번이 2월 26일". -고 꼬리 여섯 → 하나.
- "저는 이쪽이 좋아요. 이거 드리는 쪽"(흐름 ①번 지적, 바 50, 사 55): 말을 지우고 유진이 수레 아랫칸을 군화 끝으로 밀어 넣는 행동으로.
- 울렁거림 핑퐁(흐름 5 ×, 사 55 되받기, 플랫폼 24): 삭제. 유진은 돌아와 클립보드를 치우고 볼펜이 한 박자 멈춘다.
- 결과 통지 순서(사 48, 흐름 7, 문장 39, 플랫폼 30): 도현 "결과는 저한테도 옵니까" → 유진 "알려 드려요. 여백에 적으셨잖아요". "제 손에 오는 종이는 끝까지 읽어요"(경구) → "저한테 오는 건 다 읽어요".
- 인식표 걸기(나 33, 아 52): 유진 말대로 기존 줄 걸쇠를 풀어 꿰고 다시 채움. 판 수 둘 → 셋(나 34).
- P-16 자리의 속(마 29, 바 43, 아 53·56, 플랫폼 21·34, 다 30): "그 번호의 주인은 밤마다 등 뒤에서 코를 골았고, 나가는 날 국밥을 사겠다고 했다" 한 줄을 P-16 직후에. 결말 독백은 그것을 되받는 한 문장 '국밥 산다던 사람이 지금 어디서 자나'(아 57: 직접 속말).
- 묻지 않는 까닭 문장(가 2·3, 다 16, 문장 33, 아 52·53·57, 플랫폼 25): "그 말과 그녀의 이름이 같은 칸에" 삭제. "열흘 전 퇴실 서류 앞에서 그는 P를 모른다고 했다" 한 문장만.
- 지시어·피동·주어 없음(가 1·3, 문장 4·6·8·9·30·34·36, 아 57): 체온계는 유진이 넣었다 뺌, "그 칸"→차트에 한 줄, "구멍 줄은 어긋난 데가 없었다"→"한 줄로 맞아 있었다", "그 두 줄"→"로트 번호 둘이 적힌 면", 클립보드는 유진이 밀어 넣음, "적으시는 거예요, 그거"→"뭐 적으세요".
- 흔한 동작·하는 일 없는 문장(라 25 ×4, 문장 21·29·32·44, 다 17): 고개 끄덕임, 입꼬리, "도현은 그녀를 보았다", "대답은 바로 왔다", "첫 줄을 읽었다", "볼펜 소리가 났다", "트럭은 시동을 켠 채 그대로" 삭제. 차트 덮기/손 얹기 중복 → 덮고 달력 쪽으로.
- 자국 반복(다 17, 바 44, 플랫폼 32·33·35): 소멸 문장 삭제. 자국은 눌림·남음 둘만. 판 부딪힘은 걸 때와 복도 한 번씩.
- "주간 주"(나 40, 문장 2, 플랫폼 1, 아 51): 시간표 두 문장 삭제. 야간은 유진 "밤 근무시죠"에 맡김.
- 그 밖: "찼다"→"차가월다"(다 11, 문장 13), "네 번 걸렸다"→횟수 삭제(다 11, 문장 15), "-네"→"-네요"(사 46), 반장=류정우 표기(문장 23), "칸은 … 줄은 넷"(문장 27), 볼펜 출처(나 34, 문장 42: 유진이 내밈), 총 위치(문장 3: 내리기 전에), 분홍 줄 출처(문장 5, 바 50: 함석에 베였던 자리), "1차 완료"와 3회차 칸(문장 10·32: "세 번 다 들어갔어요", "마지막 칸"), 무릎 높이 설명(문장 22, 아 51, 플랫폼 15: 앉으며 무릎이 모서리에 닿음), 클립보드가 이미 책상에 있던 것(아 52, 플랫폼 16), 호출 사이 도현의 몸(아 54: 새 판을 쥠), 일곱에서 바늘(다 17: 유지 — 8장부터의 버릇, repeat_ok).
