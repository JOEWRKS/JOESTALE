- [33] "도현은 쇠줄을 입에 물고 두 손을 목 뒤로 보냈다. … 걸쇠가 물리는 소리가 났고" — 문제: 유진은 "지금 거신 줄에 같이 거시면 돼요"라 했고 설계서도 처치자 판은 같은 줄에 더 건다고 하는데, 본문은 판에 딸린 별도의 쇠줄을 새로 목에 걸고 걸쇠를 잠근다. 기존 줄에 꿰는 순서(걸쇠 풀기 → 판 꿰기 → 다시 잠금)가 없고, 줄을 입에 무는 이유도 앞에 없다. — 수정: 기존 줄의 걸쇠를 풀어 새 판을 꿰어 다시 잠그는 동작으로 바꾸거나, 별도 줄로 거는 것이면 유진의 "지금 거신 줄에 같이" 대사를 고친다.
- [34] "걸쇠가 물리는 소리가 났고, 가슴에서 판 두 개가 한 번 부딪쳤다." / "걸을 때마다 가슴에서 판 두 개가 맞부딪쳤다." — 문제: 기존 판 두 개에 처치자 판이 더해져 가슴에 판이 세 개인데 부딪치는 것은 계속 "두 개"로만 쓰여 수량이 맞지 않는다("새 판은 … 튀었다"와도 겹쳐 읽힌다). — 수정: 첫 문장은 "판들이 한 번 부딪쳤다"로, 뒤 문장은 "판 두 개가 맞부딪쳤고 새 판은 …"으로 새 판을 분리해 적는다.
- [34] "도현의 볼펜은 그 칸을 지나 서명 칸으로 바로 갔다." — 문제: 도현의 필기구는 수첩에 쓰던 연필(몽당연필)이고 볼펜은 유진 것인데, 도현이 볼펜을 쥐게 된 장면이 없다. — 수정: 유진이 볼펜을 건네는 한 줄을 앞에 두거나 "도현은 연필 대신 건네받은 볼펜으로"로 출처를 적는다.
