# 15장 처치실 대본 v3 (1회차 반영: 유진의 설명 턴 셋(인식표·입회·날짜)을 도현의 되묻기로 쪼갬, '이쪽이 좋아요'는 아랫칸을 발로 밀어 넣는 행동으로, 울렁거림 핑퐁 삭제, 결과 통지는 도현이 먼저 묻고 여백은 그 답으로, 인식표는 기존 줄 걸쇠를 풀어 꿰기, 체온·손 줄은 -요로. v1·v2 보관). 대사·독백만.
