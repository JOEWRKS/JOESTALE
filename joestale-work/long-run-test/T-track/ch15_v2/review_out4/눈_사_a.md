(도현 대사 전체: "예." / "이게 있으면 물려도 안 변하는 겁니까." / "저건 이제 저한테는 안 오는 겁니까." / "중위님은 몇 번 서셨습니까." / "오늘 맞은 약 번호입니다." / "4월 말입니까." / "결과는 저한테도 옵니까.") — 문제: 도현의 말 전체에 군말·감탄 같은 것이 하나도 없고, 답은 "예."로 네 번 끊겨 같은 모양이다("병 먼저 보시죠"/"예.", "적으셨죠"/"예.", "근무시죠"/"예."도 같은 틀) — 수정: 격식 어미는 유지하되, 한두 곳은 짧은 숨(머뭇거림 한 마디, "아," 같은 감탄, 말끝을 흐림)이나 "예" 대신 고개·간단한 말 등 다른 받음으로 바꾼다. 길이는 지금보다 반 마디 길게.
- [55] "이게 있으면 물려도 안 변하는 겁니까." / "저건 이제 저한테는 안 오는 겁니까." — 문제: 두 물음이 "(지시어) … 안 ~는 겁니까" 같은 틀이라 사람이 말한 것보다 한 틀에서 찍어낸 듯 읽힌다(둘 다 부정 + 겁니까 + 묻는 쪽이 처지를 한 줄로 정리해서 물음) — 수정: 하나는 틀을 바꿔 짧게(예: 값을 아는 사람이 하는 확인조의 한 마디, 또는 눈으로만 묻고 유진이 먼저 답하는 쪽)로 하고, 두 물음이 같은 길이·같은 끝으로 나란하지 않게 한다.
