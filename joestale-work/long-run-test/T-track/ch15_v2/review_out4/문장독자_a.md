끝까지 읽고 싶었는가: 예. P-16과 유진의 반응이 궁금해서 끝까지 읽었다.

가장 크게 걸린 세 곳: 16번(P-16이 누구인지 이어지지 않음), 10번(양식과 "넘어간다"가 무슨 뜻인지 모름), 12번(판이 목에 있다가 손에 있음. 17, 26번도 같은 어긋남).

되풀이되는 버릇:
1. 무엇인지 밝히지 않은 채 "그거, 저건, 표, P, 점" 같은 지시어와 기호를 던져 놓고 독자가 짐작하게 한다. 뒤에서 풀리지도 않는다.
2. 같은 물건(판)의 자리가 목줄과 손으로 장면 안에서 어긋난다.
