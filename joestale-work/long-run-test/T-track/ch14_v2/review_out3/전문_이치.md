## 설계서 쪽 오류·불일치
- 대장 assumptions 6만 원의 근거 '5장 저 혼자 12만 원은 이번 달 못 내요'와 values '배터리 넷 12만 원 중 제 몫'(6만)이 서로 다르다. 본문은 몫 6만이라 values 쪽과 맞다. 5장 대사의 12만 원 주체를 대장에서 정리해야 한다.
- 대장 assumptions의 도현 대사 '내가 어떻게든 한다'와 본문 '내가 갚아'는 문구가 다르다(뜻은 같음). 대장은 문구가 아닌 행동으로 적는 편이 안전하다.
- numbers에 '한 통'·'일곱 줄'이 중복. '한 통'은 문자에만 쓰인다.
