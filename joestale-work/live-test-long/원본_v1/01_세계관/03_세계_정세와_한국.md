# 03. 세계 정세와 한국

사용자 전제(원문 요지)를 작가 진실로 고정하고 그 아래 디테일을 채운다. 굵은 글씨는 사용자 전제.

## 1. 세계(2034년 봄)

| 지역 | 상태 | 디테일 |
|---|---|---|
| 미국 | **가장 잘 유지** | 연방정부 기능 유지(덴버 이전). 미시시피 서쪽 "그린 벨트" 안정, 동부 대도시 뉴욕·필라델피아·애틀랜타는 봉쇄 상태. 군 전력의 60% 보전. 석유·곡물 자급. 해외 주둔군은 **한국·일본·바레인·독일 람슈타인** 4곳만 유지, 나머지 철수. 미국의 관심은 "동맹 중 살아남을 곳에 투자" → 한국 안전구에 장비 지원이 이어지는 이유 |
| 유럽 | **부분 유지** | 독일 남부·스위스·오스트리아·북유럽 3국 유지. 프랑스는 파리 함락, 남부만. 영국은 스코틀랜드와 잉글랜드 남부가 분리된 채 유지. 이탈리아·스페인 해안 도시만. EU는 명목상 존속(브뤼셀 상실, 빈에서 회의) |
| 러시아 | **멸망** | 2032년 1~3월 모스크바 붕괴, 중앙정부 소멸. 극동 블라디보스토크·하바롭스크는 군벌화. **극동 러시아군 무기고가 동해로 흘러나옴** → 한국 밀수 7.62×39(AK) 체계의 원천. 핵무기는 미·중이 2032년 공동 작전으로 회수했다고 발표(진위 불명, 작중 미해결) |
| 아프리카 | **거의 멸망** | 사하라 이남 통신 두절. 남아공 케이프타운, 모로코·이집트 북부 해안만 소식. |
| 중동 | **건조 기후로 나쁘지 않음** | 바이러스가 60℃·건조·자외선에 약함(바이러스 문서 1절). 사우디·UAE·이스라엘·요르단 안정. **석유 수출 지속** → 미국-걸프-동북아 해상 수송선이 세계 경제의 척추. 오히려 전쟁 전보다 영향력 상승. 이란은 북부 습윤 지대 붕괴, 남부 유지 |
| 동북아 | **그나마 유지** | 한국(아래). 일본: 혼슈 서부·규슈 유지, 도쿄권 봉쇄, 해상 격리 성공. 중국: 중앙정부 시안 이전, 연안 대도시 상당수 상실, 내륙은 성(省) 단위 자치. 대만 유지. 북한: 2031-12 이후 정보 두절, 휴전선 이북 감염체 남하는 **DMZ 지뢰·철책이 막음**(아이러니) |
| 동남아 | **거의 끝** | 고온다습 + 인구 밀도. 싱가포르만 섬 봉쇄로 유지. 해상 난민이 남중국해→동중국해→한국 남해로 → 부산 외항 난민선 문제(4~5권 소재) |

세계 공급망: 석유(중동→미국·동북아), 곡물(미국→동맹), 탄약(미국·한국 자체 생산), 의약품(스위스·독일 남부·한국·일본). 한국은 **탄약·조선·반도체(일부) 생산국**으로 미국에게 "지켜야 할 동맹"이다.

## 2. 한국

### 2-1. 사실 사슬(패턴 34)

2031-10-08 인천항 컨테이너 선원 발병(첫 국내 사례) → 10-20 인천·부천 통제 실패 → 11월 김포·고양·서울 서북부 붕괴, 정부 "수도권 서부 봉쇄" → 11-25 서울시청 상실 → 12-02 **정부 대전 이전**(세종은 평지라 방어 불리, 대전은 산과 하천) → 2032-01 한강 교량 전면 폭파(23개 중 19개), 강남 격리 → 2032-03 「국가비상사태 특별조치법」(안전구·수색조·무기 등록) → 2032-06 적응자 등록령 → 2032-09 한강 이남 방어선 안정 → 2033 "정리의 해"(안전구 외곽 소탕) → 2034 현재 안정 2년째, 그러나 수도권 서부·강북은 미회복.

### 2-2. 정부와 통제 수준

| 항목 | 값 |
|---|---|
| 정부 | 대전 임시정부(정부대전청사). 대통령·국회(재적 1/3 생존, 대전에서 운영) 존속. 계엄 아님, "특별조치법" 체제 |
| 통제 범위 | **안전구 안은 통제, 밖은 명목뿐.** 지방에는 지자체·군부대·자경단이 뒤섞인 "준(準)자치" |
| 군 | 병력 약 22만(전쟁 전 50만). 징병 유지. **주한미군 2.2만 유지**(평택 캠프 험프리스, 오산 공군기지). 한미연합사가 사실상 중부권 방어의 두뇌 |
| 치안 | 안전구 내 경찰. 밖은 수색조·자경단. 사형 복원(특별조치법 12조: 교상 은폐·약탈 살인) |

### 2-3. 지역 상태 지도

| 권역 | 상태 | 비고 |
|---|---|---|
| **대전·세종·청주 삼각 안전구** | 중앙 | 인구 약 310만(피난민 포함). 정부·연구소·탄약창(대전 3군수지원사). 외곽에 이중 철책 + 하천 |
| 평택·오산 미군 권역 | 미군 통제 | 한국인 출입 허가제. 장비·식량이 새어 나오는 "미군 시장" |
| 서울 강남 격리구 | 고립 유지 | 한강 남안 서초·강남·송파 일부. 인구 약 60만. 대전과는 경부고속도로 "회랑"으로만 연결(주 2회 호송) |
| 서울 강북·수도권 서부 | **미회복(적색)** | 감염체 밀도 최고. 수색조 최대 수입원이자 최대 사망지 |
| 수원·용인·화성 | 회색(부분) | 삼성 평택·화성 반도체 라인 일부 가동(미군 보호). 자경단 다수 |
| 강원 | 산지 거점 | 원주·춘천 자치. 군부대 주도. 감염체 밀도 낮음 |
| 충남 서해안 | 회색 | 당진 제철 가동. 해상 난민 상륙지 |
| 전라 | 부분 유지 | 광주 안전구(인구 90만). 곡창 → 식량 공급원. 대전과 호남고속도로 회랑 |
| 경상 | 유지 | **부산·울산·창원 산업항** 유지. 조선소·탄약 생산. 부산은 대전 다음 가는 제2 안전구(인구 200만). 대구는 2032년 함락 후 2033년 일부 회복 |
| 제주 | 완전 격리 | 해상 봉쇄 성공. 인구 유입 금지. "낙원 소문"의 진원 |

### 2-4. 한국만의 밀덕 포인트

- **탄약 자급.** 풍산 안강·동래 공장 가동. 5.56·7.62·9mm·12.7mm 생산. 그래서 한국군·수색조 표준은 5.56 K2 계열이고, 미군 5.56 호환 → 미군 시장과 연동.
- **밀수 7.62×39 체계.** 극동 러시아에서 동해로 AK-74M(5.45)보다 **구형 AKM(7.62×39)**이 더 많이 들어왔다(군벌이 신형은 남김). 자경단·밀수 수색조는 AK + 7.62×39 체계. 4급(껍데기)에 5.56보다 7.62×39가 낫다는 "현장 믿음"이 있고, 이것이 사실인지가 작중 밀덕 논쟁(작가 진실: 두개골 관통력은 비슷, 몸통 저지력은 7.62 우세, 그러나 몸통 사격은 어차피 무의미).
- **DMZ.** 북에서 내려오는 감염체는 지뢰·철책에 막혔다. 전방 사단이 남쪽으로 돌아서 방어선이 됐다. 전방 부대가 가장 온전한 전투력.
- **K-방산 재고.** K2 소총·K14 저격·K6 중기관총·K-151 전술차·K808 장갑차가 민간 수색조에게 "불하"된다(특별조치법 부칙). 미군 장비(M4A1, M110, Mk 48)는 미군 시장에서 **물물교환**으로.
