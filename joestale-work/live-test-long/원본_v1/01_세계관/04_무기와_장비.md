# 04. 무기와 장비

밀덕 포인트 원칙: **실존 장비, 실제 제원, 현실 제약**. 무한 탄약·무음 권총·헤드샷 자동 명중 없음. 전술은 "소리 관리 → 교상 방어 → 퇴로 확보" 순.

## 2. 소음기와 소리 관리

| 항목 | 값 |
|---|---|
| 5.56 소음기 + 보통탄 | 발사음 약 135dB → 반경 300m 1급 반응. 초음속 균열음은 못 없앰 |
| 5.56 소음기 + 아음속탄 | 약 120dB, 150m. 단 가스 부족으로 작동 불량 ↑, 유효 사거리 100m |
| .22LR 소음 아음속 | 약 112dB, 50m. "손뼉 소리" |
| 비소음 5.56 | 165dB, 600~800m(도심 반사). **금기** |
| 작전 규칙 | 첫 발은 소음, 발각되면 비소음 전환하며 철수. "조용히 들어가서 시끄럽게 나온다" |
| 현장 소음기 | 미군 SureFire, 국산 S&T, **자작 오일필터 소음기**(자경단, 5발이면 망가짐) |

## 3. 교상 방어(방호)

감염은 교상만. 방탄보다 **방교(防咬)**.

| 부위 | 장비 | 비고 |
|---|---|---|
| 목 | **케블라 넥가드**(경찰견 훈련 보호구 개조) | 1급 교상 1순위 부위. 수색조 필수 |
| 팔 | 케블라 슬리브 + 가죽 바이트 슬리브 | 2급 질주 시 팔을 내미는 반사 → 팔 교상 2순위 |
| 손 | 메카닉스 장갑 + 니트릴 속장갑 | 적응자 S1 부작용 대처 |
| 몸통 | 플레이트 캐리어는 **사람 상대용** | 감염체는 몸통을 안 문다(옷). 약탈자·자경단 충돌 대비 |
| 다리 | 두꺼운 캔버스, 정강이 보호대 | 쓰러진 1급이 발목을 문다 |
| 머리 | 헬멧(FAST 계열) + NVG 마운트 | 낙하물·사람 |

## 4. 광학·전자

| 장비 | 특성 | 작중 포인트 |
|---|---|---|
| NVG(PVS-14, 국산 KAN/PVS-04K) | 단안/양안. 달빛 없으면 IR 조사기 필요 | 적응자 2단계는 NVG 없이 반달 아래 20m 식별 → "눈 좋은 놈" |
| 서멀(FLIR 계열, 국산 TAS-970K) | **감염체는 체온 28~31℃ → 배경보다 어둡게.** 사람은 밝게 | "열 꺼진 놈"이 보인다. 단 여름 낮 지면 온도 30℃면 감염체가 배경에 묻힘 → 여름 낮은 서멀 무용 |
| 무전 | PRC-999K(군), 바오펑 UV-5R(민간) | 민간 주파수는 자경단이 감청. 수색조는 호출명 사용 |
| 드론 | DJI 매빅 계열, 군용 리모아이 | 뭉침 정찰. 프로펠러 소리에 2급이 반응 → 고도 80m 이상 |
| 교상 감지 | 체온계 + HNV 신속항원키트(15분, 정확도 85%) | 양성 → 48시간 격리. 적응자는 늘 양성이라 **등록증 없으면 사살 규정** |
