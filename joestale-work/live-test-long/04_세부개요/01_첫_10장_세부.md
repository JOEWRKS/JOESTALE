# 1권 첫 10장 세부 개요

항목 출처: **핵심 사건·목표 감정·관건 선택·금지 공개·5단 구성·결미 훅**은 상위 과제가 정한 항목(스킬 미규정). **설계 재료**(사물 3·행동 2·비시각 감각·숫자·원인→결과)와 **첫 문장 신체 표지**(패턴 29)·**금지 목표**(감정어 → 방향 → 치환 각도)는 스킬 1단계 설계서 규정. 본문은 쓰지 않는다.
장 길이 기준 4,500~6,000자(작성자 결정). 날짜는 03_개요와 같고 요일은 2034년 실제 달력(3/3 = 금)을 따른다(검수 지적으로 정정). 지식 범위표(02_인물)에서 ×인 사실을 입에 올리는 인물이 없도록 장마다 대조했다.

## 1장 탄피 (3/3 금, 16:40 게이트 3-동문)

| 항목 | 내용 |
|---|---|
| 핵심 사건 | 3-2조 복귀 검사. 탄피 봉지 세기(90 = 탄피 + 잔탄). 도현 1발 모자람 → 벌점 1. 개 체온 검사 실랑이. 회색 테두리 카드. 대기실 복귀, 하은 편지 한 줄(인물 카드: 첫 등장 1장 끝) |
| 목표 감정 | 셈으로 버티는 일상. 금지 목표: "불안했다" → 방향 **셈을 멈추지 못함** → 치환 각도 ① 탄피를 두 번 센다 ② 벌점표의 숫자를 입으로 읽는다(≤ 2) → 오독 가능성: 꼼꼼함으로 읽힐 수 있음 → 도현의 "형 또 세요?"로 방향 고정 |
| 첫 문장 신체 표지 | 왼팔 소매 위로 흉터를 문지르는 손, 그 손이 봉지로 간다 |
| 관건 선택 | 도현의 모자란 1발을 **자기 잔탄에서 채워 넣을 것인가.** 넣으면 조장 대조표가 틀어진다. 건우는 넣지 않고 벌점을 도현에게 둔다 → 조장이 "건우야, 탄피."로 건우 봉지를 먼저 받는 이유(조장은 건우의 셈을 믿는다) |
| 금지 공개 | 임상·강화 코스·사총 전부. 건우가 적응자라는 것은 카드 색으로만 |
| 5단 구성 | ① 줄: 컨테이너 벽, 체온계, 개에게 항원 키트를 들이대는 경찰과 장미란 "얘는 사람 아니에요" ② 셈: 봉지, 89, 도현. 건우가 주머니 속 편지 봉투를 만지고 "무벌점" 칸을 입으로 읽는다(걸린 것을 여기서) ③ 전환: 조장이 대조표를 입으로 읽는다 "건우 90, 도현 89." 건우의 손이 자기 봉지로 갔다가 멈춘다(채워 넣을지 망설임) ④ 절정: 벌점표에 도현 이름, 조장의 침묵. 절정 표지: 흉터 위 소매를 쥔 손 ⑤ 결: 대기실 커피포트, 하은 편지 한 줄. 결 표지: 편지를 쥔 손이 봉투를 주머니 깊이 넣는다 · "오빠, 보증 서류 다시 내래."("탄피 줍지 말고—"는 10장) |
| 결미 훅 | 게시판 분필 글씨 "미군 합동 건 설명회 3/6 14시" 아래 누군가 적은 "적응자만" |
| 설계 재료 | 사물: 탄피 봉지·항원 키트 상자·회색 테두리 카드 / 행동: 탄피를 손바닥에 열 개씩 올려 센다, 카드를 리더기에 두 번 댄다 / 비시각: 탄피의 황동 냄새(화약 잔향), 컨테이너 벽의 쇳소리 / 숫자: 90, 89, 벌점 1 / 원인→결과: 도현이 1발을 못 찾았다 → 벌점표에 이름이 오른다 → 보증인 서류의 "무벌점" 칸이 건우 머리에 뜬다 |
| 5.56 자리(07) | 90발 체계 설명 없이 **세는 행동**으로만 |

## 2장 17번 (3/4 토, 09:10 연구동 2층 투여실)

| 항목 | 내용 |
|---|---|
| 핵심 사건 | 주 2회 투여. 번호표 17. 윤서 "17번, 서건우 씨." 호박색·무색 앰플 두 개, 비율은 윤서의 종이에. 배석호가 복도에서 "차 선생, 17번 수치 좀 봅시다." 건우는 장갑을 벗다 손끝이 둔한 것을 센다 |
| 목표 감정 | 번호로 불리는 사람의 거리. 금지 목표: "소외감" → 방향 **번호가 이름보다 먼저 온다** → 각도 ① 윤서가 번호를 부르고 이름을 뒤에 붙인다 ② 건우가 번호표를 접어 주머니에 넣는다 → 오독: 무심함으로 읽힐 수 있음 → 번호표를 버리지 않는 행동으로 고정 |
| 첫 문장 신체 표지 | 출동 장갑 속에 끼는 니트릴(S1 현장 대처)을 벗는데 왼손 검지 끝이 늦게 따라온다 |
| 관건 선택 | 손끝 저림을 **투여 기록지의 "증상" 칸에 적을 것인가.** 적으면 비율이 바뀌고(억제제 ↑) 작전 투입이 늦어진다. 건우는 적지 않는다 → 이 선택이 13장 윤서의 "요즘 어둠에서 잘 보여요?"를 부른다 |
| 금지 공개 | 비율표의 뜻, 촉진제가 무엇인지. 윤서가 아는 것은 "비율표를 받는다"까지(△ 전). 배석호는 "수치"만 말하고 "코스"를 말하지 않는다 |
| 5단 구성 | ① 냉장고 컴프레서 소리에 맞춰 윤서의 입술이 일정하게 움직인다(건우가 보는 것, 초를 세는지는 짐작) ② 호명, 알코올 솜을 흉터를 피해 붙여 주는 작은 호의(온기)·앰플 확인·피하 주사 ③ 전환: 배석호 "차 선생" ④ 절정: 건우가 증상 칸을 비워 두고 서명. 독백 "두 주만."(수량) 절정 표지: 펜을 쥔 왼손 검지가 펜대를 늦게 감는다 ⑤ 결: 윤서가 비율표를 **뒤집어** 놓는다(건우 시점에서는 종이가 뒤집히는 것만). 결 표지: 소매를 내리며 흉터를 한 번 문지른다 |
| 결미 훅 | 윤서 "다음 주엔 비율이 바뀝니다." 건우 "뭐가요?" 윤서는 다음 번호를 부른다. "18번." |
| 설계 재료 | 사물: 번호표 17·앰플 2(호박·무색)·비율표 종이 / 행동: 장갑을 벗는다, 증상 칸을 비운 채 서명한다 / 비시각: 냉장고 컴프레서 소리, 알코올 솜의 찬 기운 / 숫자: 17, 5ml, 주 2회 / 원인→결과: 증상을 안 적는다 → 억제제를 올릴 사유가 기록에 없다 → 저림이 계속된다(3권까지). 결미의 "비율이 바뀝니다"는 배석호의 정기 조정(건우 증상과 무관, 윤서는 받은 표대로) |

## 3장 설명회 (3/6 월, 14:00 3-2 대기실)

| 항목 | 내용 |
|---|---|
| 핵심 사건 | 문정환 등장(봉투) "노 조장님, 미군 합동 건은 제가 조정합니다." 에밀리 소개 "강 에밀리입니다. 성이 먼저… 맞죠?" 조건 셋: 등록 적응자 수색조원 / 사격 검정 / **기준 채혈.** 도현이 빌딩 7 소문을 꺼낸다. 에밀리가 K2 가스조절기 얘기를 하자 건우가 받는다("혹한기엔 한 칸 올립니다" — 위치 번호는 쓰지 않음, 실제 교범 수치 (확인 필요)) |
| 목표 감정 | 쓸 만한 사람으로 보이는 자리를 처음 발견함. 금지 목표: "설렘" → 방향 **말이 길어진다** → 각도 ① 건우의 대사가 이 장에서만 세 문장을 넘는다 ② 조장이 "건우야" 한 마디로 끊는다 → 오독: 잘난 척 → 에밀리가 메모하는 행동으로 방향 고정 |
| 첫 문장 신체 표지 | 의자가 모자라 벽에 기댄 등이, 봉투가 책상에 놓이는 소리에 벽에서 떨어진다 |
| 관건 선택 | 에밀리의 "Any questions?"에 **채혈을 물을 것인가, 총을 물을 것인가.** 건우는 총(M4 광학)을 묻는다. "채혈"이라는 말에 손이 흉터로 갔다가 멈춘 뒤라, 채혈은 묻지 않는다 → 문정환이 그 침묵을 본다(8장 복선). 문정환은 건우의 임상 참여를 이미 안다(지식표 ○): 조건 낭독 전에 참석자 카드를 걷어 번호를 대조하는 행동으로 그 앎을 독자에게 비친다 |
| 금지 공개 | 빌딩 7은 소문으로만(도현 △). 에밀리는 미군 상부 목적 ×(2권까지)이므로 "치료 협력"이라고만 말한다. 문정환은 "조정"이라는 말만 쓴다 |
| 5단 구성 | ① 대기실에 의자가 모자란다 ② 문정환의 조건 낭독 ③ 전환: 에밀리의 한국어 어순 확인 → 웃음 → 도현의 소문 ④ 절정: K2 가스조절기 문답, 건우의 긴 대사. 절정 표지: 말하는 동안 벽에서 떨어진 등이 앞으로 기운다 ⑤ 결: 에밀리가 명단 여백에 뭔가 적는다(건우는 못 본다, 조장이 본다). 결 표지: 등이 다시 벽에 닿는다 |
| 결미 훅 | 조장이 나가면서 건우에게만: "너 이름 적혔다." |
| 설계 재료 | 사물: 서류 봉투·K2 가스조절기(말로만)·명단 종이 / 행동: 봉투를 책상에 눕힌다, 여백에 적는다 / 비시각: 커피포트 끓는 소리, 봉투 종이 냄새 / 숫자: 조건 3, 가스조절기 한 칸, 명단 여백 1 / (채혈 날짜는 10장에서 처음 공개) 원인→결과: 8장 제외의 원인은 임상 기록 자체(문정환은 이미 안다) → 건우가 채혈을 안 묻는 것은 문정환의 확신을 굳히는 계기일 뿐 → 8장에서 문정환이 건우를 보지 않고 서류만 읽는다 |

## 4장 씨앗 (3/8 수, 10:00 지정 구역 폐건물: 약국·에어소프트 매장)

| 항목 | 내용 |
|---|---|
| 핵심 사건 | 물자 회수 임무. 약국에서 아목시실린, 에어소프트 매장에서 수직손잡이·슬링(피카티니 규격 그대로 맞음). 약국 뒤 계단에서 KM193 20발 탄창 발견. 조장 "그건 줍지 마라." 건우 "K2엔 들어갑니다."(대여총은 K2C1, 조원들은 "K2"로 줄여 부른다 — 전 장 공통) 1급 둘, 못 둔기로. 벽에 페인트 표식 "한남" 두 글자 — 장미란 "한남 애들 왔다 갔네." 조장 "거래하러 왔겠지."(한남 자경대는 서울 한남동 거점 고유명, "자경단"은 일반명) |
| 목표 감정 | 쓸 수 있는 것을 두고 나와야 하는 손. 금지 목표: "아쉬움" → 방향 **손이 먼저 가고 규정이 뒤에 온다** → 각도 ① 탄창을 집었다가 내려놓는다 ② 대신 그립을 집는다(민수품이라 소지는 합법, 대여총에 단 채 반납은 금지 — 08 §1) → 오독: 순종 → 주머니에 자경단 탄피 하나가 "들어 있었다"로 고정 |
| 첫 문장 신체 표지 | 못 둔기 손잡이의 테이프가 땀에 미끄러진다 |
| 관건 선택 | **탄창을 두고 나올 것인가.** 둔다(조장 말). 그러나 탄피 하나는 모른 채 주머니에 → 5장에서 꺼내 보일러실 .22 옆에 둔다. 27장의 "KM193 탄피 섞임"은 이것이 아니라 26장 권혁이 던진 탄창에서 온다 |
| 금지 공개 | 자경단 무기 구성(M16A1 7할 등)은 설명하지 않는다. 표식과 탄창 하나로만. 권혁 이름 없음 |
| 5단 구성 | ① 매장부터 들어간다(개가 먼저), 조 정지 2회. 도현 "형, 이 매장 내가 리뷰했던 데야." 건우 "별 몇 개."(온기) ② 약국: 아목시실린 21정 통 3개 ③ 전환: 약국 뒤 계단의 탄창, 두 대사. 탄창 옆에 떨어진 탄피 하나를 무심코 쥐어 주머니에(건우는 세지 않는다). 바람 독백 "호송 때 이거 스무 발이면…"(질문형 아님, 수량) ④ 절정: 1급 둘, 턱밑·측두부, 소리 안 내기. 절정 표지: 테이프 감은 손잡이를 고쳐 쥐는 손 ⑤ 결: 약국에서 매장으로 되돌아가 그립·슬링, 벽의 페인트. 결 표지: 그립을 쥐어 보는 손, 저림 때문에 홈이 늦게 느껴진다 |
| 결미 훅 | 복귀 트럭에서 주머니를 뒤지니 탄피가 하나 더 있다. 바닥 각인(헤드스탬프)이 K100과 다르다 |
| 설계 재료 | 사물: KM193 20발 알루미늄 탄창·수직손잡이·페인트 표식 / 행동: 탄창을 집었다 내려놓는다, 못 둔기를 두 번 휘두른다 / 비시각: 약국의 시럽 썩은 단내, 계단의 발밑 유리 소리 / 숫자: 20발, 1급 둘, 아목시실린 3통 / 원인→결과: 조장이 못 줍게 한다 → 건우가 그립을 줍는다 → 7장 레일 자국 |
| 5.56 자리(07) | KM193 vs K100의 차이는 **바닥 각인**으로만(1970~90년대 생산 각인) |

## 5장 보일러실 (3/9 목, 21:00 회색 구역 집)

| 항목 | 내용 |
|---|---|
| 핵심 사건 | 바닥 밑 .22 권총(루거 마크 IV)·사제 소음기·140발. 어제 탄피를 그 옆에 둔다. 도현 방문(사총을 아는 유일한 사람), 제원 농담. 하은 무전(회랑 호송 편 중계, 3분): 보증인·6,000C·주거. 건우 보유 2,100C. 바람 독백 "하은아, 몇 달이면 돼." |

| 첫 문장 신체 표지 | 명단 종이 앞에서 흉터 문지르던 손이 별표에 닿는다 |
| 관건 선택 | **조건을 받을 것인가.** 받는다. 받지 않으면 하은이 멀어진다(5장 셈). 독자는 2장·9장의 윤서 행동을 알고 있어 "연구소에서"의 무게를 건우보다 먼저 느낀다 |
| 금지 공개 | 배석호·문정환이 왜 돌아섰는지(건우를 미군 안에 두고 채혈을 연구소가 쥔다)는 **건우 시점 밖**. 건우는 "에밀리가 밀어붙였다"로만 안다. 라벨 두 장은 18장 |
| 5단 구성 | ① 대기실, 게시된 명단 ② 11명, 별표 하나 ③ 전환: 조장의 질문, 문정환 "행정 절차", 에밀리 "I asked for you." ④ 절정: 채혈 날짜가 처음 적힌다, 4/10, D-21. 건우 "연구소에서요?" 문정환 "관리 대상이니까요." 절정 표지: 별표를 누르던 손끝이 눌리는 감각을 못 느껴 두 번 누른다 ⑤ 결: 편지. 결 표지: 편지를 읽는 동안 흉터 문지르던 손이 멈춘다 |
| 결미 훅 | 편지 마지막 줄 "탄피 줍지 말고 네 몸이나 주워 와." 건우가 편지를 접어 **보증 서류 봉투에** 넣는다(1장부터 주머니에 있던 봉투) |
| 설계 재료 | 사물: 명단 종이·별표·편지 / 행동: 별표를 손끝으로 누른다, 편지를 서류 봉투에 넣는다 / 비시각: 종이 접는 소리, 커피포트 식은 냄새 / 숫자: 11명, 별표 1, 4/10, D-21 / 원인→결과: 에밀리가 요청했다 → 연구소가 조건을 붙였다 → 채혈이 연구소 손에 들어갔다(18장) |
