# 전체 분권(10권) 개요

설계 축(2026-11-02 S9 관문, 사용자 "추천대로 진행"): 10권 / 1권 45장 / 시점 건우 단일 3인칭 제한(스킬 D2) / 1권 압력 주선 = 미군 기준 채혈(전력 발각 시계), 부선 = 동생 이주 조건 / 로맨스는 윤서 먼저, 에밀리는 첫 등장(3장)은 이르되 비중은 후반 / 김도현 3권 생사·10권 결말 방향은 사용자 결정 보류(두 갈래 표기).
스킬이 규정한 것: 형식(6-B)과 걸린 것(stake)을 먼저 정한다. 권별 분권 자체는 스킬 미규정(작성자 결정). 날짜·수치는 세계관 문서 사실 사슬과 대조했다.

## 2. 전권 압력선(3층)

| 층 | 1~3권 | 4~5권 | 6~7권 | 8~10권 |
|---|---|---|---|---|
| 몸 | 깊어짐: 저림·식은땀·광과민·미각 | 더 깊어짐 입구: 공격성·호출어 | 5급이 알아봄 | 경계 |
| 신분(총) | 대여 → 개인 지급 → 군 제안 거절 | 상실 → 자경단 | 미군 | 군 |
| 전력 | 모름 → 알게 됨(2) → 숨김 | 발각·추방 | 그 전력이 5급 앞에서 자산 | 전력이 해법의 재료 |

세 층이 같은 방향으로 가지 않는다: 몸이 깊어질수록 신분은 떨어졌다가(4~5권) 올라가고, 전력은 위협이었다가(1~4권) 자산이 된다(6~8권). 이 어긋남이 권 단위 반전의 엔진이다.

## 4. 1권 범위 결정(S9)

1권은 **합동 작전 제안(3장)에서 첫 합동 작전 종료와 추천서(45장)까지**, 2034-03-03(금)~05-12. 세 질문에 답이 나와야 1권이 닫힌다: ① 건우는 미군 합동팀에 들어가는가(들어간다, 조건부) ② 조장은 살아 돌아오는가(산다, 적응자가 되어) ③ 윤서는 아는 것을 말하는가(말하지 않는다, 대신 두 장의 라벨을 남긴다). 답이 나오지 않는 것 하나를 2권에 넘긴다: 건우가 자기 전력의 뜻을 아는가.
