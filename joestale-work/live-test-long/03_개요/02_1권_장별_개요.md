# 1권 「탄피」 장별 개요(45장)

기간 2034-03-03(금)~05-12. 요일은 2034년 실제 달력. 시점 건우 단일. 형식은 기(1~10)·승(11~22)·전(23~36)·결(37~45). 장 제목은 사물 하나로 고정했다(스킬 1원칙: 감정·상황 대신 그것이 남긴 사물).
압력 시계 둘: **주선 = 미군 합동 참가자 기준 채혈(4/10)과 작전일(5/1)**, **부선 = 하은 이주 신청(보증인 1 + 6,000C + 주거, 건우 보유 2,100C)**.
5.56 장면 자리는 07 문서 §8을 45장 기준으로 재배치했다(07 §8은 1권 = 10장 가정으로 쓰여 있었음 → 교차 대조에서 잡은 모순, 07에 재배치표를 덧붙이고 원표는 남김).
