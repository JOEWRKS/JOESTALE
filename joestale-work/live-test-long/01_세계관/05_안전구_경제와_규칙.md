# 05. 안전구 경제와 규칙

배경은 대전·세종·청주 삼각 안전구 중 **대전 동구 「3구역」**(옛 대동·가양동 일대, 주인공 거주). 안전구는 구역 번호로 나뉘고 구역마다 분위기가 다르다.

## 1. 화폐와 교환재

| 항목 | 값 |
|---|---|
| 공식 화폐 | **안전구 크레딧(C).** 정부 전자 배급 포인트. 신분증(적응자는 회색 테두리) 카드로 결제. 월 기본 지급 1인 900C(식량 배급 포함). 배급 쌀 1kg = 20C. 공식 상점·배급소·관리청 수수료에만 통함 |
| 실물 교환재(2026-11-02 사용자 피드백 반영) | 공식 상점 밖은 **생필품 물물교환.** 단위 재화는 **담배(1갑)**, 그다음 소주(360ml 1병), 부탄가스(1캔), 통조림(참치 1캔), 디젤(1L), 건전지(AA 4개), 커피믹스(1봉), 아목시실린(1정). 유동성 순위: 담배 > 부탄가스 > 통조림 > 소주 > 디젤 > 항생제 > 건전지 > 커피. 내구재: 휴대용 가스레인지(1대 = 담배 30갑), 침낭, 자전거 |
| 환율(암시장, 담배 1갑 = 약 60C 상당) | 소주 1병 = 1갑 / 부탄가스 1캔 = 1.5갑 / 참치캔 1 = 0.7갑 / 디젤 1L = 0.15갑(10L 묶음 거래) / 아목시실린 1통(21정) = 7갑 / 가스레인지 1대 = 30갑 |
| **총포·탄약** | **불법 희귀재.** 크레딧으로는 살 수 없고 담배 단위로만, 그것도 아는 사람 사이에서. 은어 "쇠붙이"(총)·"씨앗"(탄). 시세는 무기 문서 6절. 한국에 민간 총기가 없었으므로 공급은 전부 **국가 무기고 유출**(예비군 치장 M16A1, 전멸 부대 K2, 경찰서 K1A·리볼버, 폐업 사격장 .22 권총, 미군 잔류품 소량)이고, 그래서 가장 비싸고 가장 위험하다. 적발 시 추방 |
| 미군 시장 | 평택 권역 경계의 공식 "교환소". 달러 아니라 **물물**. 한국 쪽은 김치·소주·담배(국산)·반도체 부품·통조림, 미군 쪽은 MRE·커피·의약품·건전지·M4 부품(총기 본체·탄 제외). 미군 병사가 "분실"한 탄은 교환소 **밖**에서 |
| 금·귀금속 | 가치 폭락. "금은 못 먹고 못 태운다" |

## 2. 직업과 계층

| 계층 | 비율(3구역) | 수입원 |
|---|---|---|
| 공무원·군인·경찰 | 15% | 크레딧 월 1,500~3,000 + 주거 우선 |
| 생산직(탄약창·농장·정비) | 30% | 1,200~1,800 |
| 배급 생활자 | 40% | 900(기본). 주로 피난민 |
| **수색조** | 약 100명(20개 조, 3구역 인구 약 9만의 0.1%) | 면허제. 성과급: 코 떼기 300, 귀 태그 5, 물자 회수 평가액의 40% |
| 암시장·자경단 | 비공식(자경단은 「지역방위협력단」 등록 대상이나 대부분 미등록·서류만) | 무기고 유출품 거래, 보호비, 회랑 통행세, 생필품 중개. 관리청은 해산 대신 **등록 유도와 봉쇄 위협**으로 다룬다 |
| 적응자 | 등록 1,912명(안전구 전체 310만 중 0.06%) | 수색조 우대(면허 수수료 면제) ↔ 상점 출입 거부·주거 분리(회색 구역) 관행 |

## 3. 수색조 제도

| 항목 | 값 |
|---|---|
| 면허 | 행정안전부 외청 「안전구관리청」(2032-03 특별조치법으로 신설, 이하 관리청) 발급. 조 단위(4~6명), 조장 책임. 연 1회 갱신, 사격 검정 |
| 임무 | ① 물자 회수(지정 구역 창고·약국·병원) ② 검체 채취(코 떼기) ③ 소탕(귀 태그) ④ 생존자 구조(건당 500C, 거의 없음) ⑤ 연구소 특별 의뢰(비공개 단가) |
| 전리품 | 회수 물자는 관리청이 평가액 40% 지급, 60% 정부 귀속. 현장에서 "빼돌리기"가 관행이고 적발 시 면허 취소 |
| 출입 | 구역 게이트에서 출입 기록. 복귀 시 **전원 체온·항원 검사**. 교상자는 48시간 격리동 |
| 사망 | 조원 사망 시 가족에게 3,000C. 시신 회수 의무 없음("태그만 떼 와라") |
| 무기 | 일반 수색조는 **대여**: 출동 시 조당 K2C1 4정·K5 2정 지급, 1인 90발, 복귀 시 총기·탄피 반납 대조(무기 문서 0절). 특별수색대(2권~)는 **개인 지급**(총번 할당, 대기소 총기함). 등록 협력단은 신고 총기 거점 보관(무기 문서 0-F). 소음기·광학·NVG는 관리청 **지급·반납 품목**(소음기는 총포 부품, NVG는 통제 물자). 방호구·무전기·드론은 조 보유 |

## 4. 규칙(특별조치법과 안전구 관리청 수칙)

| 번호 | 규칙 | 위반 시 |
|---|---|---|
| 1 | 교상 6시간 내 신고 의무 | 은폐 적발 시 **추방**(안전구 밖), 전환 후 타인 감염 시 사형(12조) |
| 2 | 발열 38℃ 이상 즉시 격리동 | 격리 48시간 |
| 3 | 야간(21~05시) 게이트 폐쇄 | 밖에서 밤을 넘기면 복귀 시 72시간 격리 |
| 4 | 총포·탄약 민간 소유 금지(엽총·공기총 포함, 2032-03 전량 관리청 회수령). 수색조는 대여·반납, 탄피 회수 | 사총 적발 시 몰수 + 면허 취소 + **추방.** 탄피 미회수 10점이면 면허 정지 |
| 5 | 적응자 등록·월 1회 채혈 | 미등록 적발 시 추방. 채혈 2회 불참 시 등록 정지 |
| 6 | 회랑(고속도로) 호송 외 단독 이동 금지 | 보호 없음(자기 책임) |
| 7 | 5급(선생) 목격 즉시 보고, 생포 금지 | 보고 포상 1,000C. 생포 시도 적발 시 면허 취소(연구소 비공식 의뢰와 충돌 → 작중 갈등) |
| 8 | 격리동에서 전환 시 즉시 처리 | 가족 입회 불가 |

## 5. 3구역 풍경(장면용 고정 사물)

- **게이트 3-동문**: 컨테이너 2단 쌓은 벽, 체온계 든 경찰, 항원키트 상자, 격리동으로 가는 노란 선.
- **회색 구역**: 옛 대동 달동네. 적응자 거주 지정. 밤에 불빛이 적다(S3 광과민 + 전기 배급 적음).
- **수색조 사무소 "3-2 대기실"**: 옛 주민센터 2층. 벽에 지도, 의뢰 게시판(코 떼기 단가가 분필로), 커피포트.
- **미군 시장 가는 길**: 경부고속도로 회랑, 주 2회(화·금) 호송. 트럭 짐칸에서 보는 평택 하늘의 블랙호크.
- **연구동 2층 투여실**: 냉장고 소리, 앰플 호박색·무색, 번호표.
- **격리동**: 옛 초등학교. 교실마다 침대 6, 창문 철망, 복도 끝 "처리실".
