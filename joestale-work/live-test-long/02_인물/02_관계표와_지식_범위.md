# 관계표와 지식 범위

## 1. 관계표(1권 시작 시점, 2034-03)

|---|---|---|---|
| 서건우 → 노태섭 | 조원 → 조장 | 탄 수를 아는 사람. 아버지뻘이지만 "조장님" | 1권 후반 조장 교상, 2권 역전(건우가 조장 대행) |

| 서건우 → 차윤서 | 피투여자 → 투여 담당 | 번호로 부르는 사람. 통조림 사건 뒤 "쉰 거 가려 주는 사람" | 1권 중반 통조림 → 2권 데이터 → 5권 동행 |
| 서건우 → 에밀리 강 | 한국 수색조원 → 미군 연락장교 | 제원 얘기가 통하는 미군. M4를 쥐게 해 준 사람 | 1권 후반 주목 → 4권 전력 발각 균열 |

| 서건우 → 배석호 | 피험자 → 동장 | "보전"이라고 말하는 윗사람. 1권엔 거리 | 1권 후반 차단 시도 감지 |
| 서건우 → 문정환 | 수색조원 → 조정관 | 서류 든 사람. 불편 | 4권 추방 집행 |
| 서건우 → 권혁 | 등록 적응자 → 미등록 적응자 | 1년 앞선 자기 | 1권 후반 조우, 4권 피신 |
| 차윤서 → 배석호 | 계약직 → 동장 | 신뢰 → 의심(1권 중반 비율표) | 2권 유출 |
| 차윤서 → 에밀리 강 | 연구원 ↔ 연구원 | 1권 미접촉 → 2권 데이터 교환 상대 | 5권 동맹 |
| 에밀리 강 → 배석호 | 미군 연락장교 → 한국 연구동장 | 협력 창구, 뭔가 숨김 | 2권 의심 |
| 에밀리 강 → 문정환 | 연락장교 → 조정관 | 모든 걸 "조정"하려는 사람 | 1권부터 긴장 |
| 배석호 ↔ 문정환 | 깊은 층 공조 | 배: 연구 논리 / 문: 통제 논리. 목표는 같고 방법이 다름 | 9권 결별 |
| 노태섭 → 문정환 | 조장 → 조정관 | 규정 뒤의 사람. 조원을 뺏으려는 자 | 1권 |
| 권혁 → 관리청 | 미등록 자경단 → 해산 권한자 | 적이되 거래 상대. 서류·회수물로 봉쇄를 미룸 | 4권 봉쇄 |
| 권혁 → 서건우(2권~) | 미등록 자경단 → 특별수색대원(봉쇄 집행자) | "총번 받은 회색 양반". 1권 무기고 대치의 상대가 이제 봉쇄선 건너편에 섬 | 2권 봉쇄선 대치 → 4권 건우가 그 안으로 추방됨 |
| 권혁 → 사당·구로 등록 협력단 | 미등록 → 등록 | 배신자. 신고 보관으로 합법이 된 이웃을 "관리청 개"라 부름 | 5권 등록 협력단이 봉쇄에 협조 |
| 한도경 → 서건우 | 같은 기수 | 기억함 | 6권 |

## 2. 로맨스 선(캐빨, 사용자 전제)

| 축 | 상대 | 끌림의 근거(행동으로) | 1권 장면 | 긴장 |
|---|---|---|---|---|
| 1 | 차윤서 | 몸의 변화를 **먼저 알아봐 주는 사람**(쉰 통조림, 손끝 저림). 번호가 이름이 되는 과정 | 투여실 17번 → 통조림 → "서건우 씨"에서 "건우 씨" | 윤서가 아는 숫자가 건우를 해칠 수 있음 |
| 2 | 에밀리 강 | **같은 언어(제원)로 말하는 사람.** 건우가 "쓸 만한 사람"으로 보이는 유일한 자리 | 대기실 K2 논쟁 → 미군 사격장 M4 영점 | 에밀리가 모르는 전력. 알게 되면 신뢰가 깨짐 |
| 형태 | 삼각이되 두 사람이 서로 적이 아니다. 2권부터 윤서와 에밀리는 **데이터로 동맹**이 되고, 건우가 가운데 선다. 결말 선택은 10권(사용자 결정 보류) |

## 3. 지식 범위표(패턴 36: 누가 무엇을 아는가, 1권 시작 시점)

○ 안다 / △ 짐작·일부 / × 모른다 / (n) n권에서 알게 됨

| 사실 | 건우 | 윤서 | 에밀리 | 노태섭 | 도현 | 배석호 | 문정환 | 권혁 |
|---|---|---|---|---|---|---|---|---|
| 건우가 "임상"에 참여했다 | ○ | ○(이름) | ×(4) | ○ | ×(1 후반) | ○ | ○ | × |
| 임상 = 강화 코스(촉진제) | ×(2) | △(1 중반) | ×(4) | × | × | ○ | ○ | × |
| 경계 피험자 한도경 생존 | ×(6) | ×(5) | ×(8) | × | × | ○ | ○ | × |
| 연구 목표 = 통제 가능 전환체 | ×(8) | ×(5) | ×(8) | × | × | ○ | ○ | △(5급 봄) |
| 미군 빌딩 7 별도 연구 | ×(1 중반 소문) | ×(2) | ○ | ×(1) | △소문 | ○ | ○ | × |
| 건우 사총 | ○ | ×(5) | ×(4) | △ | ○ | × | ×(4) | ×(4) |

규칙: 세부 개요에서 어떤 인물이 ×인 사실을 말하거나 행동 근거로 삼으면 **모순**으로 잡는다(교차 대조 기준).
