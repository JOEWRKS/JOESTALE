# 인물 카드

카드 항목은 스킬 패턴에서 가져온 것만 고정한다: **첫 등장 소개**(패턴 31: 호칭 대사 + 관계어), **아는 것/모르는 것**(패턴 36: 인물은 아는 것만 말한다), **걸린 것**(패턴 38: 원하는 것·위협·온기). 나머지 항목(배경·버릇·무기·호)은 스킬 미규정, 작성자 결정.
작가 진실 기준 2034년 3월. 나이는 만.
