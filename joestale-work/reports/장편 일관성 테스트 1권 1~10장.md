# 장편 일관성 테스트 — 1권 1~10장, 추적 파일 유/무 (2026-11-04)

질문: 매 화를 쓰면서 앞 화·설정·개요와 모순 없이 유지되는가. 추적 파일이 있으면 모순이 줄어드는가. 설계는 `joestale-work/long-run-test/README.md`.

## 결론

**10장(약 3만 자) 범위에서는 두 조건 모두 모순이 거의 없고, 추적 파일 효과는 측정되지 않는다.** 스킬이 이미 장마다 요구하는 설계서(사실 사슬·대장·배경·금지 공개)와 검수 2회가 이 길이에서는 충분하다. 추적 파일은 **집필 입력으로는 보류**하고, 두 세션이 똑같이 지적한 구멍인 **검수자에게 앞 장 맥락이 없는 문제**를 먼저 고친다. 추적 파일은 그 자리(검수 입력)에서 더 쓸모가 있다.

## 블라인드 모순 수 (sonnet, 조건당 2회, 참고로 설정·인물·지식 범위표·개요·세부 전부 제공)

| | T 추적 유 | N 추적 무 |
|---|---|---|
| 판정 1 | 1 (9장 시점: 눈 감은 도현이 볼펜 움직임을 봄) | 2 (2장 "이 년째" vs 동원 14개월, 6장 "도현은 몰랐다" 서술자 단정) |
| 판정 2 | 0 | 2 (같은 자리) |

N의 2건은 두 판정자가 똑같이 잡았고, T의 1건은 한 명만 잡았다. 통과 기준(T ≤ N/2)은 숫자로는 충족이지만, 전체가 0~2건이라 차이가 아니라 바닥이다. 유형은 전부 시점(36)과 경과 기간(P1)이고 추적 파일이 담는 항목(위치·장비·수량·복선·지식)에서는 양쪽 다 0이다.

## 해석

1. **이 길이에서 일관성은 스킬 기본 절차로 유지된다.** 장당 설계서의 사실 사슬·대장과 검수 2회가 일하고 있다. 검수 지적이 장당 20~30건 나왔고 그 대부분이 처리됐다.
2. **추적 파일이 잡은 것은 T 세션의 자체 보고로 4건**(건전지 구입일, 봉투·별지 상태, 소지품 위치, AA 셈)인데, N도 같은 자리에서 모순을 내지 않았다. 효과를 분리하려면 25장 이상이나 2권 이후가 필요하다. T 세션의 절차 이탈(5/10장 미반영)도 측정을 흐린다.
3. **공통 구멍: 검수자에게 앞 장이 없다.** 두 세션이 각각 보고했다. 검수자는 해당 장 본문과 대장만 보므로 앞 장과의 모순은 작성자 기억에 의존한다. 이번에 남은 모순 3건(시점 2, 기간 1)은 모두 한 장 안에서 잡을 수 있는 종류라 검수 항목(36, 34)의 강조로 줄일 수 있다.
4. **분량이 전부 하한(3,000자) 근처.** D4의 "분량 보충 1회" 규칙이 장편 하한과 안 맞는다는 N 세션 보고와 일치. 초고가 2,500~3,100자로 나오고 보충으로 겨우 넘긴다.
5. **비용**: 조건당 서브에이전트 20회, 세션 1개당 10장. Opus 5.5로 이상 없음.

## 결정 후보

- (a) 추적 파일: 집필 입력 규정은 보류. 대신 **검수 입력으로 축소 도입** — 검수자에게 "앞 장 요약 + 시계·소지품·지식 상태 한 블록"을 준다. T의 tracking.json 중 `clock`·`characters`·`withheld_still`·`last_scene`만.
- (b) 검수 항목 34·36 강화: 눈 감음·등 돌림 같은 감각 차단 뒤 시각 서술, "~는 몰랐다"류 서술자 단정을 명시.
- (c) D2에 장편 장 분량 행(E 유형 본문 3,000~4,500자, 초고 목표 = 하한 + 20%).
- (d) 두 세션의 입력 모순 보고(T·N `issues.md`, 합 약 20건)는 `long-plan-input` 동결본의 결함이다. 본문 테스트를 더 하기 전에 입력을 한 번 고치거나, 모순은 "본문이 택한 쪽"으로 두는 규칙을 명시.
- (e) 효과 측정을 계속하려면 11~25장을 같은 두 조건으로 이어 쓰되, T의 갱신을 장마다 강제(갱신 전 다음 장 금지)한다.

### 해석

1. **분량 규칙은 세션 작성자에게 약하게만 듣는다.** 초고 중앙값 3,118(1~10장) → 3,163, 3,000 미만 4/10 → 4/15, 3,600 도달 2/15. 같은 설계서로 새 서브에이전트가 쓰면 10/10이 3,600에 닿았다(T-046). 긴 맥락을 가진 작성자는 단별 목표를 적어 놓고도 하한으로 돌아간다. 재집필(85% 미만)은 0건, 보충은 4건으로 보충 2회 규정은 쓰이지 않았다. 단별 배분도 목표에서 벗어난 채 두었다(22장 위기 370 / 결말 898).
2. **검수 지적은 장당 37건(1~10장 22건), 걸러낸 비율 25.5%.** 억지 지적 4건 중 1건. 걸러낸 사유의 대부분은 (가) 서술 연속 지적, (나) **앞 장에서 이미 소개한 용어를 다시 "첫 등장 미설명"으로 잡음**, (다) 입력이 지정한 대사. (나)는 검수자가 continuity.terms_introduced를 받고도 지적한 것이라 reviewer 40번에 "terms_introduced에 있는 용어는 제외"를 명시해야 한다. 검수자가 K131 같은 장비명을 설정 ID로 오인한 것도 같은 줄에 넣을 것.
3. **대장 밖 수치가 늘었다.** 첫 검증에서 장당 13건(1~10장 초고 2.3건, 재생성 6건). 세션은 15장 전부 초고 뒤에 대장에 수치를 추가하는 식으로 통과시켰다. "수치가 필요하면 대장에 먼저 적는다"는 규칙은 지켜지지 않았고, 분량 목표가 수치 생성을 부른다는 T-046 부작용이 여기서는 더 크다. G3가 잡아 최종에는 남지 않지만, 대장이 사후 승인 장부가 되면 대장의 검산 기능이 없어진다. 대응 후보: 초고 뒤 대장 추가 건수에 상한(예 5건)을 두고 넘으면 수치를 지우는 쪽으로 고치게 한다.
4. **절차 이탈 8건**(세션 자체 보고): 16장 갱신 순서, 11·12장 단별 목표 위치, 21장 위반 전 검수, 11·14·17장 report 덮어쓰기, 12·22장 보충 위치, 대장 수치 사후 추가, 재검수 뒤 수정 미검수, 단별 배분 미보정. 1~10장(묶음 갱신 5/10)보다는 적고 종류가 세분됐다.
5. **설정 ID 유출**: 작중 번호 P-16·P-17만 검출(의도된 번호). K5는 '권총'으로 교체.
6. **자체 결정 25건**(`T-track/issues.md` "자체 결정" 절): 11~25장 세부 개요 전체, 시범 블록 구조(5층 일곱 동·동당 1조), 21장 1발은 준영, 황의 유예 4월 연장, 점멸 네 번 등. 유예 연장과 점멸 횟수는 2권까지 이어지는 선택이라 사용자 확인이 필요하다.
