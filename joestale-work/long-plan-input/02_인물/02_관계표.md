# 02. 관계표 (A → B의 눈, 변화 권)

"눈"은 A가 B를 뭐라고 부르고 무엇으로 보는지 한 줄. "변화 권"은 그 눈이 바뀌는 가정 권과 계기(물건). 로맨스 4선은 전부 **절차 안**에서 시작한다(00 §3 톤 지침).

| A → B | 1권의 눈 | 변화 권·계기 | 바뀐 눈 |
|---|---|---|---|
| 도현 → 유진 | "한 중위님". 체온을 재러 오는 사람. 교대 시간을 묻는 상대 | 1권 말, 2차 자격 통보서를 유진이 직접 들고 옴 | 자기 몸의 숫자를 먼저 아는 사람 |
| 유진 → 도현 | "217 대상자". 열이 기준을 넘는데 자기 체온을 안 묻는 환자 | 1권, 정우 지시로 체온 기록 시각을 늦춘 날 | 공문서의 시각을 처음 고치게 만든 사람 |
| 도현 → 가을 | 민규가 말한 "회복자 아가씨". 황 사장이 노리는 사람 | 1권, 초소에서 본 불빛 위치를 지도에 찍어 준 날 | 같은 방향을 보는 사람(둘 다 그게 동생이라 말하지 않음) |
| 가을 → 도현 | "사수님". 초소 쪽 사람. 군대는 전부 연구소 편 | 1권, 불빛을 소대장에게는 보고했지만 좌표는 적어 넘기지 않은 것을 알고 | 좌표를 안 넘기는 군인 |
| 도현 → 세라 | "한빛 연구원". 바이알 봉인을 설명해 준 사람 | 2권, 수율표 사본 | 800이라고 쓰는 손 |
| 세라 → 도현 | "그 초소 사람". 가짜 감별을 묻는 밀덕 | 2권, 도현이 사본을 S4에 넘기지 않음 | 물건을 들고도 안 파는 사람 |
| 도현 → Reyes | "Captain". 소음기를 쥐여 주고 소용없다고 말한 미군 | 1권, "P-17" 발설 | 내 이름보다 번호를 먼저 안 사람 |
| Reyes → 도현 | "P-17". 명단의 무반응군 | 2권, 명단 공유 사실이 드러난 뒤 도현이 Reyes를 조사에서 빼 줌 | 번호 뒤의 사람 |
| 도현 → 민규 | "민규". 관측병. MRE 흥정 상대 | 1권 말, 진입조로 빠질 때 | 초소를 맡기고 가는 사람 |
| 민규 → 도현 | "중사님". 밤에 안 자는 사수. UDT라는 소문 | 1권, 황 사장이 초소 정보를 요구했을 때 도현이 대신 만남 | 대신 서 주는 사람 |
| 도현 → 태석 | "오 형". 쌀 끓이는 통신병 | 2권, 동원 해제 뒤 | 바깥에서 줄을 대 주는 사람 |
| 태석 → 도현 | "서 중사". 젊은 애들 중 유일하게 탄피를 세는 놈 | 1권 | 변함없음(온기의 축은 눈이 안 바뀜) |
| 도현 → 지훈 | "소대장님". 자기 K2C1을 바꿔 준 소위 | 3권, 직할 편제 연락장교로 다시 만남 | 명령과 사람 사이에 선 사람 |
| 지훈 → 도현 | "서 중사". 탄피 보고가 늘 한 자리. 상부 명단에 올라온 이름 | 1권, 구역 안 불빛 보고(좌표 없음)를 받고 "없다"고 답해야 했을 때 | 내가 거짓말을 한 상대 |
| 도현 → 정우 | "반장님". 판정하는 사람 | 3권, 증언대 | 틀린 적 없다는 게 두려운 사람 |
| 도현 → 정해성 | 2027년의 "박사님". 판정표에 '효과 없음'이라고 쓴 사람 | 4권, 판정표를 직접 보여 준 날 | 그 말이 사실이라서 더 무서운 사람 |
| 정해성 → 도현 | "P-17, 무반응군" | 2권, 규정보다 이른 2차 자격 데이터 **[금지 공개 K3]** | 두 번째 감작 사례이자 1차 이전부터 추적되는 첫 사례 = 처치 개발의 열쇠 |
| 도현 → 황 사장 | "황 사장". 가을을 압박하는 브로커 | 3권, 냉장 트럭 | 도매상의 논리를 가진 사람 |
| 황 사장 → 도현 | "그 UDT". 민규 초소의 사수 | 1권, 가짜 바이알을 한눈에 가려냈을 때 | 물건 보는 눈이 있는 놈 |
| 도현 → 서아 | "변호사님". 명단 공개를 먼저 경고한 사람 | 5권, 주인공 단체를 견제하는 쪽에 섰을 때 | 옳은 말을 끝까지 하는 사람 |
| 유진 → 가을 | "0412". 혈장 채취 명부의 번호 | 2권, S7 결성 | 번호에 이름이 붙은 날 |
| 가을 → 유진 | 피를 뽑는 쪽 사람 | 2권 | 피가 어디로 가는지 같이 묻는 사람 |
| 세라 ↔ Reyes | 공급 인수인계의 양 끝. 서로의 숫자가 안 맞는다는 것을 둘 다 안다 | 2권, 200인분의 행방 | 같은 장부의 두 면 |
| 지훈 → 유진 | "격리반 한 중위". 초소원 처치 때 전화하는 상대 | — | 변함없음 |
| 정해성 → Reyes | "Captain Reyes". 미국 측 창구. 명단 공유는 둘 다 아는 일 | 2권, 공유본이 수방사·격리반 쪽에 드러나 책임이 연구소로 옴 | 이쪽 편이 아닌 사람 |
| 서아 → 정해성 | 피고 측 증인 | 5권, 기록 공개 | — |

로맨스 4선의 겹침 규칙(하렘 요소): 네 사람은 서로를 **물건**으로 안다. 유진은 명부에서 0412를, 가을은 혈장 봉투에서 "한빛"을, 세라는 수율표에서 미군 로트를, Reyes는 명단에서 P-17을. 네 사람이 한자리에 모이는 장면은 2권 말(S7 결성)까지 없다.
