# 01. 바이러스와 감염체 (허구 요소 F1·F2 전용 문서)

본문에 가장 자주 나올 것 1위. 아래 수치는 별도 표기가 없으면 전부 (설).

## 1. 바이러스 HNV-27

| 항목 | 값 | 출처 |
|---|---|---|
| 공식 명칭 | HNV-27 (Human Neurotropic Virus 2027). 국내 법정 분류 제1급 감염병 | 명명 (설), 분류 제도 (실: 감염병예방법) |
| 전파 경로 | 교상(물림), 감염체 체액이 상처·점막에 닿음. **공기·비말 전파 없음.** 음식·물 전파 없음 | (설) |
| 체외 생존 | 표면 위에서 20℃ 습윤 6시간, 30℃ 이상 습윤 8시간, 영하 30분, 40℃ 이상 건조 20분. **전파가 교상·체액뿐이라 지역별 피해 차이에는 거의 기여하지 않는다.** 차이는 §2의 감염체 활동·수명에서 나온다 | (설) |
| 잠복기 | 교상 후 2~36시간. 상처가 머리·목에 가까울수록 짧음 | (설) |
| 전환률 | 교상자의 94%가 감염체로 전환, 6%는 고열(39℃ 이상, 24~48시간) 뒤 회복하며 항체 보유(05의 처치 연구 출발점) | (설) |
| 진단 | 신속항원키트 15분. 상처 부위 면봉으로 감염체 타액 속 바이러스를 검출한다(잠복 여부가 아니라 오염 여부를 먼저 보는 키트). 질병관리청 승인 키트를 군 격리반·보건소가 보유, 진입조에는 격리반 요원이 지참, 민간 약국 유통 없음 | (설), 유통 구조 (실 기본값: 1급 감염병 진단은 보건소·지정 의료기관) |
| 발원 | 공식적으로는 본편 시점까지 미확정. **[금지 공개]** 작가 설정: 발병 전 한·미 공동 원 프로젝트(05 §0)가 다루던 선행 균주와 HNV-27의 관계는 design.json withheld 참조. 인물 대부분은 "모른다" 또는 "짐작"(지식 범위표 02_인물/03) | (설) |

## 2. 감염체 규격

| 항목 | 보행형 W (Walker) | 발열형 F (Fever) |
|---|---|---|
| 비율 | 감염체의 약 98% | 약 2%. 교상 후 12시간 이내 전환한 젊은 성인에게서 나옴 |
| 이동 | 성인 보행 속도, 시속 4~5km. 계단 오름, 문손잡이 못 돌림 | 달림, 100m 전력 질주 가능, 300m 넘으면 체온 41℃ 넘어 쓰러짐. 회복에 20분 |
| 감각 | 소리에 반응(50m 밖 총성에 방향 전환), 시각은 10m 안쪽, 후각 없음 | 소리·시각 모두 W의 두 배 거리 |
| 통각 | 없음. 사지 손상에도 전진 | 같음 |
| 정지 조건 | 뇌간 파괴 즉시 정지. 흉부 관통은 3~4시간 뒤 출혈로 정지 | 같음. 심장 파괴는 2~3분 |
| 섭식 | 생육(사람·동물·사체)을 뜯어 삼킴. 섭식 1회에 수명 시계가 0으로 돌아감. 쥐·비둘기·개·구역 안 가축이 주 섭식원 | 같음, 빈도 두 배 |
| 수명 | 마지막 섭식 뒤 90~120일에 활동 저하, 150일 전후 정지. **정지 상태(§ 기후)에 있는 시간은 세지 않는다** | 40~60일 |
| 체온 | 자체 발열이 없다. 전환 직후 35℃에서 시작해 외기 쪽으로 천천히 수렴(실내 20℃면 하루 뒤 25℃ 안팎). 전환 판정은 **체온 저하 추세(35℃ 이하로 내려가 돌아오지 않음) + 동공 반응 소실**(03 §4) | 평시는 W와 같음(전환 초기 고열 뒤 급락). 달릴 때만 근육 발열로 41℃까지 오르고 쓰러진 뒤 다시 식음 |
| 기후: 추위 | 외기 0℃ 이하에서 이동 속도 절반. 외기 영하 10℃ 이하에서 정지(해동되면 재개). 서울 1월은 밤에 영하 10℃ 아래로 내려가는 한파가 해마다 며칠~2주(실) → **밤에 멈추고 낮에 느린** 겨울 | 외기 0℃ 이하에서 W와 같아짐 |
| 기후: 더위 | 외기 35℃ 이상 건조에서 탈수로 수명이 10~15일로 줆. 고온 다습에서는 탈수가 없어 수명 최장(150일) | 같음 |
| 소리 | W는 숨소리만. F는 전환 초기에 고열로 신음 | 초소 병사가 밤에 구분하는 근거 |

구분 속어: W "손님", F "뛰는 놈". 공식 문서는 둘 다 "감염체"고 보고서 표기는 W/F.

**구역 안 잔존 감염체가 2029-01에도 있는 이유**: ① 구역 안 섭식원(쥐·비둘기·유기견, 구역 안에 남은 사람)이 수명 시계를 되돌림 ② 겨울 정지 시간은 수명에 세지 않음 ③ 외곽선 밖 교상자가 구역 안으로 들어가 새 전환이 생김. 구역별 잔존 수는 군 추정치로만 존재(03 §2, 전부 (설)).

## 3. 교전 수칙 (국군 합참 '감염체 대응 교전규칙' 2027-11, 설)

제도의 형식(교전규칙·사격 통제·탄약 관리)은 실제 군의 것을 쓰고, 내용만 F2에 맞게 바뀐 것으로 둔다.

| 수칙 | 내용 | 밀덕 디테일 |
|---|---|---|
| 사격 부위 | 머리(눈~코 'T-박스') 우선. 흉부 사격은 저지용으로만 | 5.56×45mm K100탄(실: 국군 제식)은 흉부 명중으로 W를 쓰러뜨리지 못함. 신병에게 "가슴 겨눠라"던 사격 교육(실)이 뒤집힘 |
| 교전 거리 | W 50m 이내, F 100m 이내로 끌어들여 사격 | 소총 유효사거리(K2 460m, 실)보다 짧은 거리에서 쏘는 이유는 머리 명중률. 100m 밖 머리 명중은 훈련 병사도 30% 아래 (설) |
| 사격 통제 | 초소당 지정 사수 1명만 발사, 나머지 대기. 야간 발사는 보고 후 | 총성이 50m 밖 W를 모은다(§2). 소음기를 달아도 초음속탄의 충격파는 그대로라 W 유인을 막지 못한다(실 물리). "한 발이 열 마리 부른다"가 초소 격언 |
| 탄약 | 병당 기본 휴대 30발 탄창 6개 180발 → 초소 근무 시 2탄창 60발로 제한(M16A1의 20발 탄창은 3탄창 60발) | 탄약 소모 구조는 04·06 |
| 근접 | 교상 방지 상완·전완 보호대. 원단은 소방청 교체 주기 도래 방화복(아라미드, 실 물자)의 전용분과 국내 아라미드 원단 신규 조달(설). 각 군단 보급대가 월 약 2,000벌 제작(설), 지급은 수복 진입조 → 초소 근무자 순, 2029-01 지급률 초소 근무자의 약 60%(설). 원단 재고량 (확인 필요) | 총검술 금지. 밀면 넘어뜨리고 거리 두고 머리 사격 |
| 교상자 처리 | 점막·체액 노출자는 처치자를 포함해 36시간 인접 격리 관찰. 교상자는 ① 즉시 격리, 15분 키트 ② 양성이면 격리반 격리실에서 36시간 관찰 ③ 고열(39℃ 이상)로 가면 회복 경로 → 48시간 뒤 음성이면 회복자 등록(05) ④ 체온이 35℃ 이하로 내려가 돌아오지 않고 동공 반응이 사라지면 '전환 확정' → 군의관이 사망 판정(03 §4), 본인이 의식 있을 때 받아 둔 사전 동의서 확인 후 K5로 처분 | 사전 동의서 양식이 있다는 것 자체가 장면 재료. 전환 확정 전에는 아무도 총을 들지 않는다 |

## 5. 장면 자리 (본문에서 이 문서가 나올 곳)

- 초소 야간 근무: 숨소리로 W 수 세기, 발사 보고, 지정 사수 교대.
- 교상자 36시간 격리실: 시계와 키트, 체온계, 사전 동의서.
- 한파 해제 아침: 밤새 멈춰 있던 W가 해 뜬 뒤 한꺼번에 움직임 → 권별 압력선(③) 후보.
- F 출현 보고: "뛰는 놈 하나" 무전이 초소 전체의 자세를 바꿈.
