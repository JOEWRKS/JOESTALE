# 교차 대조 (설정 ↔ 개요 ↔ 세부)

작성 2026-11-03. 대상: 01_세계관, 02_인물, 03_개요, 04_세부개요(1권 첫 10장). 수정 전 ③·④ 원본은 `원본_교차대조전/`에 보관했다.

방법을 구분한다. **기계**는 스크립트로 실행한 검사다(요일, 복선 ▶◀와 대장, 지식표 열 수). **수동**은 작성자가 사실 사슬을 다시 계산하며 읽은 것이다. 작성자 본인의 대조라 독립 검수가 아니다.

| 날짜-요일 | ③·④의 요일 표기 45건 | 오류 0 |
| 장 수 | 1권 장별 표 | 25장 |
| 복선 대장 ↔ 장별 표 | F01~F18 | 불일치 2건(F07·F18), 오탐 1건(F06, 스크립트가 "1권 8·12" 표기를 못 읽음) |

수정 뒤 재실행: 요일 45건 오류 0, 장 25, 지식표 17행 이상 없음, 복선은 F06 오탐 1건만 남음(콘솔 인코딩이 깨져 메시지는 출력 순서로 해독했다. 스크립트의 "1권 8·12" 파싱 한계이고 표 12장에 ◀F06이 있음을 눈으로 확인).

작업 사고 기록: 수정 스크립트가 셸 구문 오류로 실행되지 않았는데 그것을 확인하기 전에 검수를 시작했다. 수정 전 문서를 읽는 검수를 결과가 나오기 전에 중단하고, 수정 적용을 확인한 뒤 다시 시작했다. 중단한 회차는 검수 횟수에 세지 않았다.

## 확인하지 못한 것

- 이 대조 뒤에도 독립 검수가 63건을 더 찾았다(검수_기록.md). 위 표의 근무 순환·AA·교상 장면·채혈 처리는 검수에서 다시 바뀌었으므로 최종값은 03·04 문서를 따른다.
- 검수 2차 반영 뒤에는 기계 검사만 다시 돌렸다(요일 45건 오류 0, 복선은 F06 오탐만). 사람이나 검수자가 다시 읽지 않았다.
- `원본_교차대조전/`에는 ③·④만 있다. ①·②의 11-02 이후 수정 전 원본은 따로 보관하지 않았다(①은 판정 스냅샷이 11-02 시점).
- 2~5권은 분권표 수준이라 장 단위 대조가 없다.
- 하계역·중계동·망우동·남태령의 세부 위치는 실지도와 대조하지 않았다(가정 표).
- 11~25장은 장별 표만 있고 세부 개요가 없어(요청 범위 밖) 대조 깊이가 1~10장보다 얕다.
