# 00. 개요와 허구 요소

작성 2026-11-02. 유형 E 기획 ① 세계관. 사용자 전제(원문): "장르는 현대 판타지로, 미지의 좀비 바이러스를 통한 인류 아포갈립스를 상정하고, 너무 무거운 분위기는 아니고 밀덕 포인트가 중요해. 추가로 인류는 아직 정부가 남아있지만 부분적으로 통제를 잃은 상태고 여전히 미국이 제일 유지가 잘 되고 있음. 유럽은 부분적으로, 러시아 멸망, 아프리카는 거의 멸망, 중동은 오히려 건조 기후로 나쁘지 않은 상태, 동북아는 그나마 유지, 동남아는 거의 끝. 나머지 디테일은 네가 채우고 중요 포인트는 로우파워 먼치킨, 성장형 먼치킨, 신체 개조(바이러스 연구를 통해), 캐빨 로맨스 첨가, 밀덕 무기 텍티컬 중요, 탄탄한 설정."

수치 표기: (실) 실제 값·계산 / (설) 허구 요소의 설정값 / (확인 필요) 임시값, 본문에 쓰지 않음.

## 1. 설계 축 (관문 결과)

| # | 축 | 선택지 | 채택 | 확인 |
|---|---|---|---|---|
| 1 | 허구 요소 | A 바이러스+감염체+적응 처치 / B 개조 없음 / C 각성 추가 | A | 사용자 미응답 → 추천 채택 |
| 2 | 시점·경과 | A 발병 2027.10, 본편 2029.1 / B +3개월 / C +5년 | A | 사용자 미응답 → 추천 채택 |
| 3 | 주 무대 | A 대한민국 / B 미국 / C 중동 | A | 사용자 미응답 → 추천 채택 |
| 4 | 감염체 규격 | A 보행형+소수 발열형 / B 전부 러너 / C 지능형 | A | 사용자 미응답 → 추천 채택 |
| 5 | 신체 개조 | A 단계적 적응 처치 / B 즉시 초인 / C 기계 의수 | A | 사용자 미응답 → 추천 채택 |
| 6 | 한국 통제 상실 형태 | A 수도 유지+통제상실구역 / B 세종 이전·서울 상실 / C 군벌화 | A | 사용자 미응답 → 추천 채택 |

뒤집히면 바뀌는 문서: 1번 → 01·05 전부, 2번 → 02·03·06의 모든 날짜·수량, 3번 → 03·04·06 전부, 4번 → 01·04의 교전 수칙, 5번 → 05 전부, 6번 → 03·04의 구역 지도.

## 2. 허구 요소 (3개, 목록 밖은 전부 현실 기본값)

| # | 허구 요소 | 1차 파급 | 2차 파급 (여기까지만) |
|---|---|---|---|
| F1 | 바이러스 HNV-27 (체액·교상 전파, 중추신경 침범) → 01 | 감염자가 감염체로 전환, 전환률·회복률 → 각국 붕괴 정도(02) | 기존 제도의 재가동·임무 변경: 계엄·통합방위 선포(03), 재난지원금 카드 틀을 쓴 배급카드(06), 군 의무부대의 격리반 임무(03), 계엄사 포고에 의한 통제상실구역 고시(03), 전환자 사망 판정 기준 변경(03 §4), 기존 병적·의무 기록 양식의 확장(회복자 등록·처분 동의 확인서·처치자 명부·인식표 뒷면 각인, 01 §3·05 §3) |
| F2 | 감염체 (보행형 W / 발열형 F, 기후에 따른 활동·수명 차이) → 01 | 교전 수칙(머리 사격, 야간 운용) 변경(04). 지역별 유지·붕괴의 기후 차이(02) | 탄약 소모 구조·예비군 재무장 순서(04·06) |
| F3 | 적응 처치 (HNV-27의 재생 기전을 전용한 단계적 처치) → 05 | 처치자 소수의 면역·회복력·단계 강화 | 처치제 배급 우선순위와 암거래(05·06). **3차 금지**: 처치자 전용 무기 체계·부대·계급은 만들지 않는다 |

F1~F3 밖의 군·법·행정·경제·의학·지리·장비는 2026년의 실제 세계가 기본값이고, 사건이 그것을 **어떻게 바꿨는지만** 쓴다. 위 표의 2차 파급에 든 제도 변경은 전부 **기존 법·기관의 틀 안에서** 운용이 바뀐 것이고 새 기관·새 법은 없다. 한국에 없던 것(민간 총기 문화·민병대·달러 유통·현상금 사냥꾼)은 생기지 않는다. 있던 것(주민등록·주민센터·예비군·민방위·한전·이동통신 3사·편의점 물류)은 남아서 축소 가동한다.

## 3. 톤 지침 (사용자 "너무 무거운 분위기는 아님")

- 공포·비극 장면은 권당 2~3장으로 제한하고, 나머지는 장비·절차·일상의 복구가 주는 **작동의 재미**로 채운다.
- 밀덕 포인트는 "장비·제도 이름 1 + 운용 디테일 1" 쌍으로만 낸다(04·05). 제원 나열 금지.
- 감염체를 부르는 말: 공식 문서 "감염체", 병사 속어 "손님"(초소에 "손님 왔다"), 발열형은 "뛰는 놈". 속어가 분위기를 가볍게 든다.
- 로맨스는 장비 점검·처치 경과 관찰 같은 **절차 안에서** 일어난다(인물 단계에서 배치).

# 01. 바이러스와 감염체 (허구 요소 F1·F2 전용 문서)

본문에 가장 자주 나올 것 1위. 아래 수치는 별도 표기가 없으면 전부 (설).

## 1. 바이러스 HNV-27

| 항목 | 값 | 출처 |
|---|---|---|
| 공식 명칭 | HNV-27 (Human Neurotropic Virus 2027). 국내 법정 분류 제1급 감염병 | 명명 (설), 분류 제도 (실: 감염병예방법) |
| 전파 경로 | 교상(물림), 감염체 체액이 상처·점막에 닿음. **공기·비말 전파 없음.** 음식·물 전파 없음 | (설) |
| 체외 생존 | 표면 위에서 20℃ 습윤 6시간, 30℃ 이상 습윤 8시간, 영하 30분, 40℃ 이상 건조 20분. **전파가 교상·체액뿐이라 지역별 피해 차이에는 거의 기여하지 않는다.** 차이는 §2의 감염체 활동·수명에서 나온다 | (설) |
| 잠복기 | 교상 후 2~36시간. 상처가 머리·목에 가까울수록 짧음 | (설) |
| 전환률 | 교상자의 94%가 감염체로 전환, 6%는 고열(39℃ 이상, 24~48시간) 뒤 회복하며 항체 보유(05의 처치 연구 출발점) | (설) |
| 진단 | 신속항원키트 15분. 질병관리청 승인 키트를 군 격리반·보건소가 보유, 민간 약국 유통 없음 | (설), 유통 구조 (실 기본값: 1급 감염병 진단은 보건소·지정 의료기관) |
| 발원 | 본편 시점까지 미확정. 인물은 전부 "모른다" 또는 "짐작" | 지식 범위표(②)용 |

## 2. 감염체 규격

| 항목 | 보행형 W (Walker) | 발열형 F (Fever) |
|---|---|---|
| 비율 | 감염체의 약 98% | 약 2%. 교상 후 12시간 이내 전환한 젊은 성인에게서 나옴 |
| 이동 | 성인 보행 속도, 시속 4~5km. 계단 오름, 문손잡이 못 돌림 | 달림, 100m 전력 질주 가능, 300m 넘으면 체온 41℃ 넘어 쓰러짐. 회복에 20분 |
| 감각 | 소리에 반응(50m 밖 총성에 방향 전환), 시각은 10m 안쪽, 후각 없음 | 소리·시각 모두 W의 두 배 거리 |
| 통각 | 없음. 사지 손상에도 전진 | 같음 |
| 정지 조건 | 뇌간 파괴 즉시 정지. 흉부 관통은 3~4시간 뒤 출혈로 정지 | 같음. 심장 파괴는 2~3분 |
| 섭식 | 생육(사람·동물·사체)을 뜯어 삼킴. 섭식 1회에 수명 시계가 0으로 돌아감. 쥐·비둘기·개·구역 안 가축이 주 섭식원 | 같음, 빈도 두 배 |
| 수명 | 마지막 섭식 뒤 90~120일에 활동 저하, 150일 전후 정지. **정지 상태(§ 기후)에 있는 시간은 세지 않는다** | 40~60일 |
| 체온 | 자체 발열이 없다. 전환 직후 35℃에서 시작해 외기 쪽으로 천천히 수렴(실내 20℃면 하루 뒤 25℃ 안팎). 전환 판정은 **체온 저하 추세(35℃ 이하로 내려가 돌아오지 않음) + 동공 반응 소실**(03 §4) | 같음. 전환 초기 고열 뒤 급락 |
| 기후: 추위 | 외기 0℃ 이하에서 이동 속도 절반. 외기 영하 10℃ 이하에서 정지(해동되면 재개). 서울 1월은 밤에 영하 10℃ 아래로 내려가는 한파가 해마다 며칠~2주(실) → **밤에 멈추고 낮에 느린** 겨울 | 외기 0℃ 이하에서 W와 같아짐 |
| 기후: 더위 | 외기 35℃ 이상 건조에서 탈수로 수명이 10~15일로 줆. 고온 다습에서는 탈수가 없어 수명 최장(150일) | 같음 |
| 소리 | W는 숨소리만. F는 전환 초기에 고열로 신음 | 초소 병사가 밤에 구분하는 근거 |

구분 속어: W "손님", F "뛰는 놈". 공식 문서는 둘 다 "감염체"고 보고서 표기는 W/F.

**구역 안 잔존 감염체가 2029-01에도 있는 이유**: ① 구역 안 섭식원(쥐·비둘기·유기견, 구역 안에 남은 사람)이 수명 시계를 되돌림 ② 겨울 정지 시간은 수명에 세지 않음 ③ 외곽선 밖 교상자가 구역 안으로 들어가 새 전환이 생김. 구역별 잔존 수는 군 추정치로만 존재(03 §2, 전부 (설)).

## 3. 교전 수칙 (국군 합참 '감염체 대응 교전규칙' 2027-11, 설)

제도의 형식(교전규칙·사격 통제·탄약 관리)은 실제 군의 것을 쓰고, 내용만 F2에 맞게 바뀐 것으로 둔다.

| 수칙 | 내용 | 밀덕 디테일 |

## 6. 수복 작전 '회복' 표준 절차 (설, 미군 CQB 교리 참조는 실)

1. 외곽선에서 TOD로 블록 관측 24시간.
2. 새벽 05시 진입. 이유는 해 뜨기 전 TOD 관측이 끝나 있고 야간 근무조와 주간 근무조가 겹쳐 인원이 가장 많은 시간이라서. 0℃ 이하인 날은 W 속도 절반(01 §2)이 덤이고, 대구·부산에서는 이 덤을 기대하지 않는다. 연막 → 2인 1조 → 건물 1층부터. 진입조는 처치자(05)와 비처치자 혼성이고 처치자 비율 상한은 절반. 비처치자가 남는 이유: 처치 수량 부족(1차 4,200명 대 진입조 소요), 처치 대상 연령(18~45세) 밖의 간부, 처치 대기 순번.
3. 층마다 "클리어" 대신 "비었다"로 보고(한국군 관행 설).
