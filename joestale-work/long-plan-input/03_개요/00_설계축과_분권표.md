# 00. ③ 권별 개요 — 설계 축과 분권표

작성 2026-11-03. 6-C ③. 수치는 별도 표기가 없으면 (설). 3인칭 제한 단일(서도현). ②에서 가정한 5권 번호가 이 표로 확정됐다.
