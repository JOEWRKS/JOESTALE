# 07. 영역별 점검

규정(scene-design 6-C ①): 영역마다 "그 분야 종사자가 읽으면 웃을 문장"을 1건 고치거나 "없음". 운용 주체 4질문(누가 보유·누가 운용·어느 기관·평시에 얼마나 흔한가)에 답 못 한 것은 삭제. 1차 검수(검수_기록.md) 뒤 갱신.

**정정(2026-11-03).** 아래 표에서 "초안"으로 적은 문장은 저장된 초안에 있던 문장이 **아니다.** 첫 작성 때 쓰지 않기로 한 후보를 "고친 문장"처럼 적은 것이다. 실제로 문서에 있다가 고쳐진 문장은 "검수 후" 쪽뿐이고, 그것은 이 점검이 아니라 서브에이전트 검수가 찾았다. 즉 작성자의 자체 영역별 점검이 실제 문장을 잡은 사례는 0건이다.

| 영역 | 찾은 문장 | 문제 | 처리 |
|---|---|---|---|
| 군 | 쓰지 않은 후보 "초소마다 열상 조준경 지급" / 검수 후 "소음기가 W 유인을 막는다" | 열상 조준경은 대량 보급 장비가 아님. 소음기는 초음속탄 충격파를 못 지움 | 삭제·수정. TOD는 대대, PVS-04K는 초소 1개. 소음기 효용은 총구 소리·청력 보호로 한정(04 §2·§3) |
| 의학 | 쓰지 않은 후보 "처치 후 즉시 면역" / 검수 후 "양성 즉시 처분" | 항체 형성에 시간이 걸림. 즉시 처분하면 6% 회복자를 다 죽여 혈장 원료가 안 생김 | 1차 3회 1주 간격 + 72시간 관찰. 교상자는 36시간 관찰 → 회복 경로/전환 확정으로 갈라짐(01 §3, 05 §1) |
| 행정법 | 쓰지 않은 후보 "교상자 안락사는 보건소 판단" / 검수 후 "계엄 포고령으로 성립" | 행정기관도 포고령도 생명권 박탈을 열 수 없음. 통합방위 사태는 적 침투가 요건 | 법적 근거 없음을 명시, 사망 판정 기준 변경 + 긴급피난 사후 면책 + 위헌 다툼 중으로 낮춤(03 §4). 갑종사태는 대통령 해석 선포문 한 줄(03 §1) |
| 경제 | 쓰지 않은 후보 "달러로 거래" / 검수 후 "쌀 주 2kg" | 달러는 없던 것. 쌀 2kg×52주×인구는 국내 생산을 넘음 | 후보는 처음부터 안 씀. 쌀은 2차 검수까지 거쳐 주 1.3kg + 밀가루 600g, 연 335만 t로 수급 범위 안쪽(06 §2) |
| 지리 | 쓰지 않은 후보 "서울 동북 외곽선 = 행정구 경계" / 검수 후 "중랑천·우이천이 외곽선" | 행정구 경계는 지킬 수 없고, 두 하천은 구역 안을 흐름 | 구역을 노원·도봉·강북 전역 + 성북 북부로 재정의, 외곽선을 북한산 능선·내부순환로·중랑천으로 구간별 기술. 중랑구는 구역 밖(03 §2) |
| 인물 | 쓰지 않은 후보 "처치자는 특수 부대로 편성" / 검수 후 "거부자는 진입조에서 빠짐" | 허구 3차 효과(처치자 부대)와 같아짐 | 삭제. 진입조는 혼성, 거부자 배제 문구 삭제(04 §6, 05 §1·§3) |
