# 06. 경제와 배급 (2029-01)

원칙: 원화와 기존 유통망이 **축소 가동**한다. 물물교환 도시·달러 경제는 없다(02).

## 1. 화폐·금융

| 항목 | 상태 | 출처 |
|---|---|---|
| 원화 | 유지. 한국은행 발권 계속. 현금 사용 비중 증가(통제상실구역 인접 지역에서 카드 단말 전원 불안) | (설) |
| 은행 | 영업 주 3일. 인출 한도 1일 50만 원 | (설, 제도 형식은 실제 예금인출 제한 사례) |
| 물가 | 쌀 20kg 소매가 발병 전 약 6만 원(확인 필요, 2024 기준 추정) → 배급 외 시장가 약 15만 원 (설) | |
| 임금 | 공무원·군인 급여 지급 중. 민간 고용은 물류·발전·의료만 정상 | (설) |

## 2. 배급 (설, 제도 뼈대는 실)

| 항목 | 내용 |
|---|---|
| 배급카드 | 재난지원금 선불카드(실, 2020년 지급 틀)를 재사용한 IC카드. 주민등록번호 연동. 주민센터 발급. 1인 주 1회 |
| 1인 주간 배급량 | 쌀 1.3kg, 밀가루 600g, 통조림 3개, 식용유 200mL, 설탕 200g, 콩 300g, 생수 6L. 환산 약 11,400kcal/주 → 하루 약 1,600kcal(성인 기준 2,500의 65%). **배급은 생존선이고 나머지는 시장 구매·텃밭.** 라면·과자는 배급 밖 시장 물품. 환산 근거는 (확인 필요, 07) |
| 쌀 수급 | 1.3kg × 52주 × 4,950만 ≈ 연 335만 t. 국내 연 생산 약 350만 t(확인 필요) + 공공비축미 + 의무수입(실: TRQ 연 약 40만 t) 안쪽 |
| 밀 수급 | 600g × 52주 × 4,950만 ≈ 밀가루 연 154만 t ≈ 밀 약 210만 t. 평시 식용 밀 수입 약 250만 t(확인 필요) 안쪽. 국내 생산이 거의 없어(실) 미국 원조 약 100만 t + 걸프 경유 상업 수입 약 110만 t(설) |
| 처치자 가산 | 1회차 접종일부터 적용. 배급을 1차 처치자 3,500kcal, 2차 4,500kcal 수준으로 증량(배급 기준 1,600 대비 약 2.2배·2.8배) → 배급소에서 처치자가 눈에 띈다 |
| 배급소 | 동 단위 1개, 초등학교 체육관·주민센터 주차장. 민방위 경비(비무장), 경찰 1명 |
| 재원 | 정부 공공비축미(실 제도, 양은 확인 필요) + 국내 생산 수매 + 미국 원조 밀·통조림(설) |
| 편의점·마트 | 영업. 배급 외 물품(과자·술·담배)은 시장가. 술은 1인 주 2병 제한 (설) |

## 5. 밀덕 포인트와 경제의 접점

- 탄약은 배급 대상이 아니다. 탄피 회수(04 §5)가 돈보다 엄격한 유일한 "화폐"처럼 작동하지만, 거래는 불법이고 거의 없다.
- 미군 PX 물자(초콜릿·커피·MRE)가 합동 훈련 뒤 한국군 초소에 흘러든다. 이것이 초소의 비공식 통화.
- 암시장 1순위는 처치제(05), 2순위는 AA 배터리(야간투시경, 04), 3순위는 담배.

## 6. 장면 자리

- 배급소 줄에서 처치자 가산을 받는 장면(눈에 띔).
- 순환 단전 시각에 배급소 체육관 전등이 꺼지고 가정집 창이 한 구역씩 어두워지는 장면(초소는 계통 전력을 안 쓴다, 04 §4).
- 미군 MRE 한 봉지로 야간 근무를 바꾸는 흥정.
