# 05. 적응 처치 — 신체 개조 (허구 요소 F3 전용 문서)

사용자 요구: 로우파워 먼치킨, 성장형 먼치킨, 신체 개조(바이러스 연구를 통해). 아래 수치는 전부 (설). 기관·제도는 (실).

사용자 결정(2026-11-03, ② 관문)으로 추가. 발병 전에 선행 균주를 다루던 한·미 공동 연구가 있었고 주인공은 그 피험자였다.

## 1. 무엇인가

HNV-27 교상자의 6%(01 §1)가 회복하며 항체를 갖는다. 그 회복자의 혈장에서 바이러스의 **조직 재생·통각 억제 기전**만 분리해 비감염자에게 단계적으로 주입하는 처치. 공식 명칭 "선택적 면역조정 처치(Selective Immunomodulation Protocol, SIP)", 군 속어 "접종", 처치자 속어 "맞은 사람".

| 항목 | 값 |
|---|---|
| 개발 | 원 프로젝트(§0) 데이터 위에서 미국 USAMRIID(실 기관) 선행 임상 1차 처치 2028-02 시작, 2028-06 1차 프로토콜 공개. 미국 2차 최초 2028-05, 3차 최초 2028-11. 한국은 국군의학연구소(실)·질병관리청(실)이 참여. 한국 1차 처치 최초 2028-06(미국 공급분), 2차 최초 2028-09, 자체 생산 2028-11부터 |
| 단위 | "1인분" = 한 단계분. 1차는 3회 주사 1세트가 1인분, 2차 이후는 1회 주사가 1인분 |
| 원료 | 회복자 혈장. 회복자 1명이 월 1회 **혈장성분헌혈**(실: 2주 간격 가능)로 **2인분** 공급. 한국 **등록** 회복자 약 1,100명 → 월 약 2,200인분이 이론 상한. 헌혈 참여율 약 45%(강제 아님, 설). 헌혈 사례는 그 달 배급 가산 3배 분(설). 암시장 혈장 시세는 그 사례의 현금 환산(5장 황 "세 배") → 투입 혈장 기준 처리량 월 약 1,000인분. **보고·배급은 월 800인분.** 차액 200의 행방은 **[금지 공개 K5, 2권]** |
| 정제 위탁 | 정제 공정 일부를 민간 제약사 한빛바이오에 위탁(실 틀: 국방 조달·위탁생산 계약, 2028-11~, 설). 원료 반입·완제품 반출은 연구소가 통제. 파견 연구원은 연구소 신분으로 격리반 로트 검수에 입회한다. 00 §2 F3 2차 파급에 등록 |
| 이상 반응 보고 | 처치 후 체온 40℃ 초과가 12시간 지속되거나 경련이 있으면 격리반이 연구소에 보고하고 대상자를 연구소 관찰 병동으로 이관(기존 군 의무 보고 체계의 확장, 설). 수방사 격리반 기준 2029-01까지 이관 4명, 복귀 0명(전국 합계는 격리반에 공개되지 않음) |
| 등록 회복자가 적은 이유 | 회복자는 격리반 격리실에서 고열 뒤 음성이 확인된 사람만 등록된다(01 §3). 구역 밖에서 격리된 교상자 약 1만 8천 명 중 6% ≈ 1,100명. 구역 안에서 회복한 사람은 등록될 길이 없고, 회복 후 신고 의무도 없다 |
| 공급 | 2028-06~09 미군 경유 미국 공급 월 600인분 × 4 = 2,400인분(2028-10 잔량 정리). 2028-11~2029-01 자체 생산 월 800 × 3 = 2,400인분. 합계 4,800인분 = 1차 4,200명 + 2차 600명(§2) |
| 형태 | 1차 처치 = 3회 근육주사(1주 간격). 단계 처치 = 각 1회 |
| 용기 | 1회분 유리 바이알 + 알루미늄 크림프 캡(실 표준). 캡 위에 국군의학연구소 위조 방지 봉인 띠(절취선·로트 각인, 설). 다시 붙이면 절취선이 어긋난다 |
| 3차 금지 | 처치자 전용 무기·부대·사회 계급은 만들지 않는다. 처치자는 같은 K2를 들고 같은 초소에 서고, 수복 진입조도 처치자·비처치자 혼성이다 |

| 단계 | 조건 | 효과 | 부작용 | 비율 |

## 4. 처치가 **못 하는** 것

- 이미 교상된 뒤 처치: 효과 없음. 1차는 1주 간격 3회로 2주가 걸리는데 전환은 2~36시간 안에 일어난다.
- 감염체를 되돌리기: 불가.
- 노화·질병 치료: 무관.
- 유전: 모른다(2029-01 기준 처치자 출산 사례 0).

## 5. 로맨스 자리 (② 인물 단계에서 배치, 여기는 세계관이 제공하는 조건만)

- 처치는 3회 주사 + 72시간 고열 관찰 → 군의관·간호장교가 처치자를 **사흘 동안 붙어서** 본다.
- 2차 처치자는 열량 4,500kcal → 식사를 챙겨 주는 사람이 생긴다.
- 체취 식별(2차 부작용) → "2차까지 맞은 사람끼리는 안다". 1차 처치자에게는 없는 감각.

## 6. 장면 자리

- 1차 처치 1회차 주사와 72시간 고열(첫 권 초반 후보).
- 혈액 검사 수치를 보고 2차 자격을 통보받는 장면(성장 표지).
- 암시장 가짜 처치제 수사.
- 미군 3차 처치자 소문(지식 범위 △).
