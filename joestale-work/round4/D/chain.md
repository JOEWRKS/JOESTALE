# 사실 사슬 (패턴 34, 초고 전)

- 시간: 진우의 야간 근무 22시~06시. 노인은 매일 새벽 3시. 보름째 날 하나만 삼. 그날 낮에 할머니 사망(점장 전언). 다음 날 3시 안 옴. 사흘 뒤(= 안 온 지 사흘) 아침 6시 교대 때 점장이 서랍을 열고 설명. 그날 새벽 3시 진우가 하나를 삼.
- 수량: 삼각김밥 늘 두 개 + 컵라면 하나. 보름째만 한 개. 영수증은 매일 한 장, 서랍에 쌓임(보름 장). 거스름돈 300원. 진열대 참치 삼각김밥 세 개 남음.
- 위치: 편의점(계산대·냉장 진열대 둘째 칸·온수기·자동문), 건너편 302호(점장 전언만).
- 인물: 진우(야간 알바), 노인, 점장. 할머니·아들은 전언.
- 결과 문장 ← 상태 변화: 영수증 두께로 날짜 ← 매일 한 장 쌓임 / 손을 멈춤 ← 하나만 집음 / 뚜껑 다시 덮음 ← 3시 반·4시 안 옴 / 뭉치 넘김 ← 점장이 서랍 열고 설명 / 진우가 하나 삼 ← 영수증 사슬 확인.

- v1b 추가: 이레째 밤 노인이 기한 긴 것을 찾고 '집에 깨어 있는 사람' + 건너편 삼 층 창에 불(복선). 안 온 날 4시 10분 진우가 밖에서 본 삼 층 창은 어두움(할머니 사망 다음 날, 할아버지는 아직 집 — 불을 안 켠 것). 마지막 날 창 어두움(아들이 모셔 감).

## v2
- 진우의 버릇은 '야간 첫 주에 붙은 것'으로 명시(노인 습관과 분리). 온수기 대사 삭제(매일 오는 손님). 안 온 날: 3시 10분 자동문 저절로 반쯤 열림 → 진우 반신반의 → 손으로 닫음 → 4시 밖에서 창 어두움. 점장은 '며칠 전'만 알고, 날짜 연결(하나만 산 날 → 다음 날 문)은 진우 독백. 뭉치는 서랍에 둠(주머니 삭제). 점장은 창고로(온수기 재사용 삭제).
- v2 재검수 후: 15일 3시 하나 → 15일 낮 할머니 사망(점장 "그제") → 16일 3시 문 반쯤 열림 → 16일 낮 아들이 모셔 감("어제") → 17일 6시 점장(오지 않은 지 이틀째) → 18일 3시 진우가 하나를 삼.

- v3 추가: 일곱 장째 밤에 노인이 이름표를 읽고 천 원을 더 올려 진우 몫 하나(온기). 열다섯 장째에는 이름표를 읽지 않음(변화 표지). 안 온 날 자동문 장면에서 진우가 부르는 것은 '할아버지'(노인이 죽었나 하는 두려움). 점장 장면에서 진우가 먼저 '할아버지는요'를 묻고 나서 전언. 결말: 하나를 사서 계산대 뒤에서 자동문을 보며 먹음(온기 장면 되받기).
