# JOESTALE — 작가의 어휘로 쓰기

원칙 출처: 허관 작가(@huh_kwan) 「글쓰기팁(어휘)」·「소재를 낚는 5단계」. 원칙·예문·변환 패턴은 [principles.md](references/principles.md). 기본값·임계값·실패 동작·출력 형식은 전부 [decisions.md](references/decisions.md)에 고정돼 있다. **그 표에 있는 것은 묻지 않는다.**

## 1원칙

부사와 형용사를 **줄인다. 없애지 않는다.** 줄어드는 이유는 명사·동사가 구체적이기 때문이어야 한다. 감정·성격·상황을 말하지 말고 그것이 남긴 **사물과 행동**을 보여준다. **묘사를 늘리라는 뜻이 아니다.** 수식어가 서 있던 자리를 감각으로 느껴지는 상황 묘사로 대체하는 것이고, 결과는 원문보다 짧거나 같아야 한다.

**서열: 직관성 > 감정의 방향 > 수식어 제거.** 치환한 문장에서 원래 상태가 1초 안에 떠오르지 않거나 사람이 실제로 쓰지 않는 말이면, 원문의 형용사·부사를 그대로 둔다(설계서 `keep_original`). 연상은 한 단계, 인식 경로(협소 = 머리를 숙인다, 낡음 = 냄새)를 따른다. 이중적 성격은 "~면서도 ~했다" 대비문 하나로, 늘 그래 온 감정은 "~곤 했다"로. 상황 묘사는 인물의 행동 시간순으로 한 문장에 행동 하나(장면을 조립하게 만드는 묘사는 공상 과제). 관계·과거는 대사 한 줄과 반응 문장 하나로, 전제 감정(그리웠다)은 써도 결론 감정(부끄러움)은 독자 몫(설계서 `premise_emotions`). 연상은 상태당 글 전체에서 한 번. 클라이맥스에서는 행동 뒤에 독백 두 문장까지(질문형·"차마 ~없었다", 설계서 `monologue`). 손해 장면에서는 인물이 한 번 저항(대사·손 뻗음)하고 세계가 반응하지 않는 대비 한 문장, 결말은 신체 반응(눈물) 한 문장으로 닫아도 된다. 상태 설명의 부정문은 구체 사물을 든 긍정형이 있을 때만 바꾸고, 한 장면은 한 자리에서 보이는 범위로. 사고 동사(생각했다)는 행동으로 풀고, 문단은 상태 요약으로 열지 않으며, 대사 사이 지문은 인물만의 작은 동작으로, 남긴 수식어는 한 명사에 하나. 첫 문장에는 핵심 감정의 신체 표지를, 긴장은 점층·의성어·더듬는 대사로, 동기 감정은 숫자를 든 독백으로, 새 인물은 호칭 대사로 소개한다. 묘사만 이어지면 지루하므로 서너 문장마다 속마음이나 대사 한 줄로 직관적 표현을 넣는다. 행동은 관습 순서와 이유를 갖고, 흐름의 사실 논리를 먼저 잇는다. 상세는 principles.md 패턴 8~34.

## 규칙 요약 (스크립트가 검사, 값은 decisions.md D3)

R1 정도부사 0 · R2 수식어 비율 ≤ 0.18(문단 ≥ 0.30, 문장 ≥ 0.50도 위반) · R3 "~한 성격이었다"류 0 · R4 감정 직설 0(대화문·`premise_emotions`·`monologue` 예외) · R5 글 전체 비시각 감각 ≥ 1(문단별 부재는 W3 note) · R6 문단당 숫자·고유명사 또는 명사 3개(대화문만 있는 문단 제외) · R7 사고 동사(생각했다·깨달았다·싶었다) 0 · R8 문단 첫 문장 상태 형용사 술어 0 · G1 조사 받침 규칙 · G2 마지막 어절 3연속 금지 · G3 설계서 대장과 본문 일치 · G4 한 명사 앞 상태 관형어 2개 이상 금지 · T1 번역투·AI 관용구 상한(이중 피동·"에 의해"는 0) · T2 문단 첫 어절 3연속 금지 · X1 작가 예문 복제 금지 · W1 문단 5문장 이상 note · W4 상투 동작(한숨·어깨 으쓱) note · W5 대사·독백 없는 서술문 5개 연속 note. 허용: 동작부사(꾹, 나란히, 비로소), 수관형사(세, 두, 맨). 검수자(5단계)만 보는 것: 배경·시대 정합성, 감정의 방향, 묘사 과잉.

## 절차

### 0단계 입력 분류와 소재 낚기

decisions.md D1 규칙으로 A 완성 글 / B 아이디어 / C 의견 / D 써줘 중 하나로 분류한다. 빠진 재료는 D2 기본값으로 채우고 설계서의 가정 표에 적는다.

소재 낚기(B·C·D 필수, A는 원문에 사물이 없을 때): ① 사물 시드 1개(입력 속 구체 명사) ② 사물과 범주·반의 관계가 **없는** 단어 1개 ③ 둘을 잇는 감각 경로 1줄(소리 → 기억, 질감 → 성격) ④ 후보 3개를 D2의 선택 순서로 고른다. 우리말샘 키가 있으면 `scripts/lookup_synonyms.py <사물> --related-check <단어>`로 관계 있음(exit 2)을 배제한다.

### 1단계 장면 설계서

[scene-design.md](references/scene-design.md) 표를 채우고 같은 내용을 [design.template.json](references/design.template.json) 형식으로 `design.json`에 저장한다(위치는 D6). **배경(시대·장소·쓸 수 없는 사물)** 을 먼저 적고, 사물 3·행동 2·비시각 감각(문단당 1)·숫자 1·원인→결과 1, 인물·장소·숫자 대장, 금지 목표(원래 감정어 → **방향** → 치환 계획 **각도 ≤ 2** → 오독 가능성), 가정 표. 모든 사물은 배경 칸과 대조한다(조선 배경에 버스 정류장 금지).

### 2단계 초고

먼저 요일·시각·수량·인물 위치의 **사실 사슬**을 한 줄로 적어 모순이 없는지 보고(패턴 34), 그 위에 설계서의 사물·행동만으로 쓴다. 행동은 그 상황의 관습 순서를 따른다(패턴 33). 부사·형용사를 세지 않는다. 작가 예문의 명사구를 그대로 쓰지 않는다. **한 상태에 문장 2개까지**, 문단은 4문장 이하. 치환한 문장만 따로 읽어 원래 감정의 반대(배려·여유·정돈)로 읽히면 다시 쓴다(principles 패턴 7).

### 3단계 기계 검증

```bash
PYTHONIOENCODING=utf-8 python skills/joestale/scripts/check_text.py draft.txt --design design.json
```

위반 목록이 나온다. 위반이 있으면 4단계. 띄어쓰기 차이(`spacing_differs`)는 보고만 한다.

### 4단계 국소 리라이트

**위반 문장만** 고친다. 전체 윤문 금지. 형용사 → 그 상태가 남긴 사물, 부사 → 그 방식으로만 가능한 동사, 감정 → 행동과 숫자(principles.md 패턴 6개). 고친 뒤 3단계를 다시 돈다. 최대 3회, 그 뒤에도 남으면 D4대로 멈추고 리포트에 적는다.

### 5단계 독립 검수와 제출

**기본은 서브에이전트다.** [reviewer-prompt.md](references/reviewer-prompt.md)의 블록에 본문과 설계서의 `ledger`·`banned_targets`·`assumptions` 세 블록만 넣어 일반 서브에이전트(저비용 모델 가능)에게 준다. seed·materials·초고·리포트는 주지 않는다. 지적은 4단계로 돌리고, 대장 쪽 오류면 design.json을 고쳐 3단계를 다시 돈다. 처리한 지적이 3건 이상이면 검수를 한 번 더(최대 2회). 서브에이전트를 띄울 수 없는 환경에서만 같은 맥락에서 하고 `검수: DEGRADED(같은 맥락)`로 표기한다.

분량은 `--length a-b`(D2 기준)로 3단계에 넘겨 리포트의 note로 받는다. 위반이 아니다.

제출은 decisions.md D5 형식 고정: 본문 → 설계서 → 검증 리포트(초고/최종 수치, 남은 위반, 검수 결과).

## 하지 말 것

- 부사·형용사를 0으로 만들려고 문장을 비틀지 않는다.
- Kiwi 오타 교정 모드를 켜지 않는다. 띄어쓰기 자동 수정을 하지 않는다.
- 현대 작가의 문체를 흉내 내지 않는다. 원칙만 따른다.
- D7의 두 경우 외에는 사용자에게 묻지 않는다.

## 설치

버전은 `VERSION`(현재 0.2.0). 이 프로젝트 안에서는 `.claude/skills/joestale` 정션으로 로드된다. 다른 프로젝트에서도 쓰려면 개인 설치:

```powershell
powershell -NoProfile -File skills/joestale/scripts/install.ps1 -Check   # ready / current / blocked
powershell -NoProfile -File skills/joestale/scripts/install.ps1 -Apply   # ~/.claude/skills/joestale 로 복사
```

기존 설치의 VERSION이 다르면 덮어쓰지 않고 blocked. `-Remove` 뒤 `-Apply`. 설치 후 새 세션부터 로드된다. 요구: Python 3 + `pip install kiwipiepy`.
