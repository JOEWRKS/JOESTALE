# JOESTALE — 작가의 어휘로 쓰기

원칙 출처: 허관 작가(@huh_kwan) 「글쓰기팁(어휘)」·「소재를 낚는 5단계」. 상세와 예문은 [references/principles.md](references/principles.md).

## 1원칙

부사와 형용사를 **줄인다. 없애지 않는다.** 줄어드는 이유는 명사·동사가 구체적이기 때문이어야 한다. 감정·성격·상황을 말하지 말고 그것이 남긴 **사물과 행동**을 보여준다. 독자가 장면을 떠올리게 하는 것은 단어의 디테일뿐이다.

## 측정 규칙 (스크립트가 검사)

| 규칙 | 기준 |
|---|---|
| R1 정도부사 | 매우·몹시·너무·정말·아주·굉장히·엄청·완전·늘·항상 등 0회 목표 |
| R2 수식어 비율 | (MAG + VA + XSA + MM − 화이트리스트) / 내용어 ≤ 0.18 |
| R3 상태·평가 서술 | "~한 성격이었다", "~해 보였다", "~한 분위기였다" 금지 |
| R4 감정 직설 | 슬펐다·기뻤다·불안했다·답답했다 등 금지 → 행동·사물로 |
| R5 감각 다변화 | 문단당 비시각 감각(촉각·청각·후각·미각·온도) ≥ 1 |
| R6 구체화 | 문단당 숫자 또는 고유 사물명 ≥ 1 |
| G1 조사 | 받침 규칙 위반(경첩가, 바람를, 그녀은, 손톱로, 서울으로) 0건 |
| G2 어미 반복 | 같은 종결어미 연속 4회 이상 금지 |
| G3 대장 일치 | 설계서의 인물·장소·숫자가 본문과 다르면 위반 |
| 허용 | 동작부사(꾹, 나란히, 비로소, 천천히), 수관형사(세, 두, 맨)는 R2 계산에서 제외 |

## 절차

### 0단계 입력 분류와 소재 낚기

입력을 네 유형 중 하나로 분류하고 빠진 재료를 채운다. 묻지 않는다. 가정한 것은 설계서의 "가정" 표에 적어 결과와 함께 돌려준다.

| 유형 | 입력 | 보충 |
|---|---|---|
| A 완성 문장/문단 | 고칠 글이 있음 | 리라이트 모드. 사물 시드는 원문에서 뽑는다(문 → 경첩) |
| B 단순 아이디어 | "비 오는 날 재회" | 소재 낚기 → 장면 설계. 시점·분량 기본값 선언 |
| C 러프한 의견/감상 | "지하철이 답답해" | 핵심 명사를 사물 시드로, 감정어는 R4 치환 목표로 등록 |
| D "써줘" 요청 | "짧은 단편 하나" | 분량·시점 기본값 선언 + **소재 낚기 필수** |

소재 낚기(B·C·D 필수, A 선택): ① 사물 시드 1개(입력 속 구체 명사, 없으면 장면의 첫 사물) ② 사물과 범주·반의 관계가 **없는** 단어 1개(구름/중학교처럼 다른 세계의 것) ③ 둘을 잇는 감각 경로 1줄(소리 → 기억, 질감 → 성격) ④ 후보 3개 중 감각이 가장 구체적인 것을 고른다.

### 1단계 장면 설계서

[references/scene-design.md](references/scene-design.md) 질문지를 채운다. 사물 3개, 행동 2개, 비시각 감각 1개, 숫자 1개, 인물·장소·시간 대장, 가정 표. 인물의 성격·감정은 쓰지 않고 그것이 남긴 흔적만 적는다.

### 2단계 초고

설계서의 사물·행동만으로 쓴다. 이 단계에서 부사·형용사를 세지 않는다. 어휘가 구체적이면 저절로 준다.

### 3단계 기계 검증

```bash
PYTHONIOENCODING=utf-8 python skills/joestale/scripts/check_text.py <본문.txt> [--design <설계서.json>]
```

JSON으로 R1~R6·G1~G3 위반 문장 목록이 나온다. 위반이 있으면 4단계로.

### 4단계 국소 리라이트

**위반 문장만** 고친다. 전체 윤문 금지(문체가 평평해진다). 형용사는 그 상태가 남긴 사물로, 부사는 그 방식으로만 가능한 동사로, 감정은 행동과 숫자로 바꾼다. 패턴은 principles.md의 변환 6개. 고친 뒤 3단계를 다시 돈다. 최대 3회.

### 5단계 독립 검수와 제출

가능하면 별도 맥락(서브에이전트)에서 [references/cliche-list.md](references/cliche-list.md)의 검수 체크리스트만 들고 읽게 한다. 주술 호응, 시제, 지시어 불명, 설계서와 본문의 뜻 어긋남을 지적받아 4단계로 보낸다. 서브에이전트를 띄울 수 없으면 같은 맥락에서 하되 리포트에 DEGRADED로 표시한다.

제출물: 본문 + 설계서(가정 표 포함) + 검증 리포트(전후 수치, 남은 위반과 이유, 검수 지적과 처리).

## 하지 말 것

- 부사·형용사를 0으로 만들려고 문장을 비틀지 않는다. 작가의 예문에도 "나란히", "비로소", "꾹"이 남아 있다.
- Kiwi 오타 교정 모드를 켜지 않는다. "녹슨"을 오타로 본다.
- 띄어쓰기 자동 수정을 하지 않는다. 보고만 한다.
- 현대 작가의 문체를 흉내 내지 않는다. 원칙만 따르고, 문체 프로파일은 저작권 만료 작품에서만 만든다.
