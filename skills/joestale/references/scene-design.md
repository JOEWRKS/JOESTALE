# 장면 설계서 (쓰기 전에 채운다)

설계서는 Markdown 표로 본문 앞에 두고, 검증용으로 같은 내용을 JSON(`--design`)으로도 저장한다.

## 1. 입력 분류

| 항목 | 값 |
|---|---|
| 유형 | A 완성 글 / B 아이디어 / C 의견 / D 써줘 / E 기획(장편 설정·개요, 6-C) |
| 원문 또는 요청 | (그대로) |
| 분량 기본값 | (예: 400~600자) |
| 시점 기본값 | (예: 3인칭 제한) |

## 1-B. 배경 (필수, I-13)

| 항목 | 값 |
|---|---|
| 시대 | 입력이 암시하는 시대(조선 / 1930년대 / 현대 …). 암시 없으면 "현대 한국" |
| 장소·계층 | 농촌·도시·궁중·빈민가 등 |
| 쓸 수 없는 사물 | 그 배경에 없는 것(조선이면 버스·전기·편의점·휴대폰). 사물 시드·결합 시드·재료 전부 이 칸과 대조 |
| 허구 요소 (E) | 장편 기획이면 허구로 두는 것의 목록(보통 3개 이하: 바이러스·개조 체계·감염체). 목록 밖은 전부 현실 기본값 |
| 현실 기본값 (E) | 허구 밖의 군·법·행정·경제·의학·지리·장비 운용은 입력 시점의 실제 세계가 기본값이고, 사건이 그것을 **어떻게 바꿨는지만** 쓴다. 장비·제도는 누가 보유·누가 운용·어느 기관·평시에 얼마나 흔한가에 답 못 하면 지운다. 허구의 파급은 2차 효과까지(허구 위에 허구 금지). 그 나라에 없던 것(민간 총기 문화·민병대·달러 유통)은 생기지 않고, 있던 것(주민센터·예비군·주민등록)은 남아서 작동한다. **단, 사용자 전제가 요구하는 요소(자경단·암시장 등)는 지우지 않고 그 나라에 있던 제도의 변형으로 어떻게 생기는지를 쓴다**(예비군 치장물자 + 엽총 보관 무기고 → 자경단) |
| 수치 출처 (E) | 수치마다 **(실)** 실제 값/계산, **(설)** 허구 요소의 설정값, **(확인 필요)** 임시값을 표기. (확인 필요)는 본문에 쓰지 않고 개요에 `[확인 필요]`로 남긴다 |

## 5. 금지 목표

입력에 있던 감정어·정도부사·상태형용사를 적고, 각각을 무엇(사물/행동/숫자)으로 바꿀지 적는다. **방향**은 원래 감정의 부정/긍정·능동/소극, **문장 수**는 최대 2, **오독 가능성**은 치환 문장만 읽었을 때 반대 감정으로 읽힐 수 있는지(I-14).

**인식 경로**는 사람이 그 상태를 평소 무엇으로 아는지(협소 = 머리를 숙인다, 낡음 = 냄새·삐걱 소리). 치환은 그 경로 위에 있어야 하고 연상은 한 단계여야 한다. 치환이 원문보다 덜 직관적이면 **원문 유지**라고 적고 `keep_original`에 넣는다. 반응 문장에 남길 전제 감정은 `premise_emotions`에 적는다(글당 1문장, 결론 감정은 안 됨). 결합 시드를 본문에 쓰지 않기로 했으면 `seed.used: false`와 이유를 적는다. 클라이맥스 독백(패턴 18)은 `monologue`에 구절로 적는다(한 자리, 두 문장까지). 손해 장면의 저항 대사는 `materials.dialogue`에, 결말의 신체 반응은 `closing_body`에 한 문장으로 적는다(패턴 19·20).

| 원래 표현 | 방향 | 인식 경로 | 치환 계획 (각도 ≤ 2) | 문장 수 | 오독 가능성 |
|---|---|---|---|---|---|
| 작고 낡은 방 | 부정·결핍 | 협소 = 입구 높이 / 낡음 = 냄새 | 머리를 숙여야 드나듦 / 눅눅한 나무·나프탈렌 냄새 | 2 | 없음 |
| 공기는 늘 축축하고 무거웠다 | 부정 | 이미 직관적 | **원문 유지** | 1 | — |
| 외롭고 고집스러운 성격 | 부정·양면 | 양면은 대비문 | 난로를 고치려 하면 화를 내면서도 춥지 않은지 물어옴 | 1 | 한 면만 쓰면 실패 |
| 가난 | 부정·결핍 | 결핍의 표지 | 빨간 글씨 독촉장 세 통 + 가격표 다시 보고 손 거둠 | 2 | 없음 |

## 6-B. 형식 (스토리의 줄기가 있는 글 필수, 패턴 37)

글의 목적에 맞는 형식을 먼저 정한다. 소설은 기·승·전·결(갈등-고조-해소), 수필은 경험→전환→성찰 등. 분량은 기준이 아니다. 문장 치환만 하는 A·B·C 유형은 비워 둔다. 아래 표는 소설 기본형이고, 단계 이름은 글의 형식에 맞게 바꾼다.

| 단계 | 문단 | 사건 | 시점 인물의 신체 표지 | 장르 감정 |
|---|---|---|---|---|
| 기 | | 상황과 갈등의 씨 | | |
| 승 | | 불안·의문의 표지 | | |
| 전 | | 고조(헛기대·공포·충돌 한 장면) | | |
| 결 | | 해소(전언·의례·행동) | | |

JSON은 `structure: {"form": "소설 기승전결", "stages": [{"stage","paragraphs","event","body_sign","emotion"}], "stake": {"wants","threat","warmth","feeling_monologue"}}`. 단계가 비면 쓰지 않는다.

**걸린 것(패턴 38).** 형식과 함께 적는다. 시점 인물이 원하는 것 한 문장(`wants`), 그것이 위협받는 장면(`threat`), 위협 앞에 두는 온기 한 장면(`warmth`), 바람·두려움을 담는 독백 또는 대사 한 줄(`feeling_monologue`, 감정어 없이 질문형·호출). 넷 중 하나라도 비면 감정이 설 자리가 없다.

## 6-C. 장편 기획 (E 유형 필수: 설정·분권·장별 개요가 본문 앞에 필요한 글)

장편·연재는 본문 설계서(1~6-B)보다 먼저 이 절을 채운다. 단계는 넷이고 순서를 바꾸지 않는다. 각 단계는 **설계 축 관문**으로 연다: 뒤집히면 문서 절반이 바뀌는 결정 3~6개를 선택지와 추천으로 먼저 보이고 확인받은 뒤 쓴다(decisions D7 예외). ①의 **고정 질문** 셋은 반드시 포함한다: 허구 요소 목록, **핵심 설정의 모델**(고정 단계표인가 연속 모델인가), **성장 경로**(장비·능력·지위가 어떤 제도적 사다리로 자라나: 대여→지급→압수→파밍 등). 그 밖의 축은 핵심 제도·시점·권수·1권 범위·압력선·로맨스 배치·결말 방향에서 고른다. 사용자가 답하지 않아 추천안으로 갔으면 가정 표에 축마다 적는다. 지적을 받으면 그 자리만 고치지 않고 바뀌는 다른 문서·규칙을 먼저 나열한 뒤 전부 고친다.

| 단계 | 파일 | 필수 항목 |
|---|---|---|
| ① 세계관 | `01_세계관/` 영역별 파일 | 허구 요소 목록과 현실 기본값(1-B), 수치 출처 표기, 영역별 점검(군·의학·행정법·경제·지리·인물: 그 분야 종사자가 읽으면 웃을 문장을 영역마다 1건 고치거나 "없음"). 본문에 가장 자주 나올 것 상위 3개는 전용 문서(생산·배급·효과·가격·장면 자리)까지. 장르 소재 디테일은 "장비·제도 이름 1 + 운용 디테일 1" 쌍 |
| ② 인물 | `02_인물/` 카드·관계표·지식 범위표 | 카드: 소개 대사(31)·아는 것·걸린 것(38)·호(변화 지점 권). 관계표(A→B 눈·변화 권). **지식 범위표**: 사실 × 인물, ○ 안다/△ 짐작/× 모른다/(n) n권에서 앎 + **독자 기지 열**(독자가 그 사실을 아는 장). ×인 인물이 그 사실을 말하거나 행동 근거로 삼으면 모순 |
| ③ 권별 개요 | `03_개요/` 전체 분권·1권 장별 표 | 분권표(권 기능·핵심 사건·시작→끝 상태·권이 약속하는 것과 아껴 둘 것). 1권 장별 표: 사건·압력(시계·셈)·복선 심기▶/회수◀·결미 훅. **압력선** 주선·부선 각 1개 이상, 시계(마감일·잔고)가 있는 것. **복선 대장**(ID·심는 장·회수 장·상태). 반전 배치(권당 1~2). **금지 공개 목록**(무엇을 몇 장까지 안 밝히나). 6-B 형식(기승전결·stake)은 권 단위로 |
| ④ 장별 세부 | `04_세부개요/` 첫 n장 | 장마다 핵심 사건·목표 감정(금지 목표 → 방향 → 치환 각도 ≤ 2)·첫 문장 신체 표지(28)·관건 선택(하면/안 하면 잃는 것)·**금지 공개**(이 장에서 아직 밝히지 않는 것)·5단 구성(단계별 신체 표지)·결미 훅·설계 재료(사물 3·행동 2·비시각 감각·숫자·원인→결과). 날짜는 실제 달력 요일, 경과 시간은 앞 장 수치에서 계산 |

검사: 기획 문서는 check_text.py 대상이 아니다(본문 전용). **① 뒤**에 reviewer-prompt 기획 문서 모드(P5·8·P6 중심, "1단계만 완료" 조건 명시)로 1회 검수하고, 검수 전 판을 `원본_v0/`에 보관한다. ③·④가 끝나면 **교차 대조표**(설정 ↔ 개요 ↔ 세부: 지식 범위표·복선 대장·날짜 사슬·금지 공개·수량)를 파일로 남기고 다시 기획 문서 모드로 검수한다. 모순은 고치되 원본은 보관한다. 본문은 그 뒤 장마다 D 유형으로 1~5단계를 돌리며, 대장·배경·금지 공개는 기획 파일에서 가져온다. 2장부터는 설계서 `continuity`(앞 장 요약·시계·인물 상태·아직 밝히지 않은 사실·마지막 장면)를 앞 장 final.txt에서 채워 사실 사슬의 출발점으로 쓰고 검수자에게도 준다(decisions D2 앞 장 맥락).

JSON은 `planning: {"fiction_elements": [], "axes": [{"stage","axis","options","chosen"}], "pressure_lines": [{"line","clock"}], "foreshadow": [{"id","planted","paid","status"}], "withheld": [{"fact","until"}], "knowledge": [{"fact","who": {"인물": "○|△|×|(n)"}, "reader_knows_at"}]}`.
