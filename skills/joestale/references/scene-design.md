# 장면 설계서 (쓰기 전에 채운다)

설계서는 Markdown 표로 본문 앞에 두고, 검증용으로 같은 내용을 JSON(`--design`)으로도 저장한다.

## 1. 입력 분류

| 항목 | 값 |
|---|---|
| 유형 | A 완성 글 / B 아이디어 / C 의견 / D 써줘 |
| 원문 또는 요청 | (그대로) |
| 분량 기본값 | (예: 400~600자) |
| 시점 기본값 | (예: 3인칭 제한) |

## 1-B. 배경 (필수, I-13)

| 항목 | 값 |
|---|---|
| 시대 | 입력이 암시하는 시대(조선 / 1930년대 / 현대 …). 암시 없으면 "현대 한국" |
| 장소·계층 | 농촌·도시·궁중·빈민가 등 |
| 쓸 수 없는 사물 | 그 배경에 없는 것(조선이면 버스·전기·편의점·휴대폰). 사물 시드·결합 시드·재료 전부 이 칸과 대조 |

## 2. 소재 낚기 (B·C·D 필수)

| 항목 | 값 |
|---|---|
| 사물 시드 | 입력 속 구체 명사 1개 |
| 결합 시드 | 사물과 범주·반의 관계가 없는 단어 1개 |
| 감각 경로 | 둘을 잇는 한 줄 (예: 소리 → 기억) |
| 탈락한 후보 | 2개와 탈락 이유 |

## 3. 장면 재료

| 항목 | 최소 | 값 |
|---|---|---|
| 사물 | 3 | 상태가 남긴 흔적이 보이는 것 (녹슨 경첩, 세 겹 스티커) |
| 행동 | 2 | 그 방식으로만 가능한 동사 포함 |
| 비시각 감각 | 문단당 1 | 촉각·청각·후각·미각·온도·신체감각 중. 문단 수만큼 미리 적는다(R5는 문단 단위) |
| 숫자 | 1 | 횟수·개수·시간 |
| 원인→결과 | 1 | "당기자 → 쇳소리" 꼴 |

## 4. 인물·장소·시간 대장 (G3 검증 기준)

| 종류 | 이름/값 | 속성 |
|---|---|---|
| 인물 | | 나이·호칭·관계 |
| 장소 | | |
| 시간 | | 계절·시각 |
| 숫자 | | 본문에 나올 **2 이상의 수량과 숫자** 전부(두 번, 세 겹, 둘째 날, 72시간). 수량 1(한 번, 하나)은 적지 않아도 됨. G3가 본문↔대장 양방향으로 대조 |

## 5. 금지 목표

입력에 있던 감정어·정도부사·상태형용사를 적고, 각각을 무엇(사물/행동/숫자)으로 바꿀지 적는다. **방향**은 원래 감정의 부정/긍정·능동/소극, **문장 수**는 최대 2, **오독 가능성**은 치환 문장만 읽었을 때 반대 감정으로 읽힐 수 있는지(I-14).

| 원래 표현 | 방향 | 치환 계획 (각도 ≤ 2) | 문장 수 | 오독 가능성 |
|---|---|---|---|---|
| 가난 | 부정·결핍 | 빨간 글씨 독촉장 세 통(사물) + 가격표 다시 보고 손 거둠(행동) | 2 | 없음 |
| 위축 | 부정·소극 | 점원이 고개 들자 손 거둠 / 나갈 때까지 고개 안 듦 | 2 | "배려"로 읽힐 행동 금지 |
