# 결정표 — 회색지대 없애기 (2026-10-29, 사용자 지시 "회색지대 없이 기능 채워줘")

이 표의 값은 사용자가 바꾸기 전까지 고정이다. 스킬은 아래 항목에 대해 **묻지 않는다**. 바꾸고 싶으면 사용자가 이 파일을 고치거나 요청 안에서 지정한다(요청 안의 지정이 우선).

## D1 입력 분류 규칙

| 판별 순서 | 조건 | 유형 |

| 플랫폼 표본 | 호흡·설명의 입·장의 끝 기준은 references/platform-norms.md의 표본 수치를 따른다. 표본 본문은 저장하지 않고 수치·기법·짧은 예만 적는다 | T-058: 카카오페이지 무료 대여분(작품별 대여권) |
| 수락 관문 | 검증기 통과(R9·L1 포함) + 사용자 판독. 모델 블라인드 판정은 모순·뜻 확인에만 쓴다 | T-051: 모델 판정 2/2 새 판, 문장 독자 지적 44 → 25, 사용자는 새 판이 더 나쁘다고 봄. 모델 독자는 뜻이 닿는가를, 사용자는 힘 안 들이고 읽히는가를 잰다 |
| 인물 관문 | 최종본에서 눈 사(46~48) 0건. 지적이 있으면 대화 장면 단위로 다시 쓰고 눈 사·문장 독자 재검수(최대 2회), 남으면 리포트에 적고 제출. 관문 검수는 독립 2회를 합친다(같은 본문에 문장 독자 7건/39건) | T-055. T-053 검수 8개가 민규 사정 누락·동음이의를 0건 짚음 |
| 검수자 한 명의 항목 수 | 9개까지. 눈(가~마)마다 따로 띄운다. 새 항목은 자리가 있는 눈에, 없으면 새 눈. 기계가 볼 수 있는 것(겹치는 문장, 수치 되풀이, 사고 동사 등)은 검증기로 옮기고 검수자 항목에서 뺀다 | T-050 |
| 검수자에게 주는 설계서 | design.json의 `ledger`·`banned_targets`·`assumptions`·`setting` + 연재·장편이면 `continuity`. JSON 그대로. 눈마다 reviewer-prompt 표에 적힌 블록만. seed·materials는 주지 않는다(검수자가 작성 의도를 모르게) | I-9, T-040 |
| Kiwi 미설치 | 3단계 건너뛰지 않음. `pip install kiwipiepy` 안내 후 중단 |
| 입력이 한국어 작문이 아님(코드·보고서·번역 요청) | 스킬을 쓰지 않는다고 한 줄로 말하고 일반 처리 |

## D5 출력 형식 (고정)

```
## 본문
(글)

## 설계서
유형 / 시드 / 재료 표 / 대장 / 가정 표

## 검증 리포트
| 항목 | 초고 | 최종 |
수식어 비율, 정도부사 수, 감정 직설 수, 조사 오류, 어미 반복, 번역투 건수, 분량(기준 범위)
회차별 위반 수: 1회 n → 2회 n → 3회 n
남은 위반: (없음 또는 목록과 이유)
오탐 보고: (없음 또는 규칙·문장·이유)
검수: PASS / DEGRADED / 지적 n건 → 처리 n건 / 재검수 (실행·생략 이유)
```

A 유형(리라이트)은 본문 앞에 "원문" 절을 추가한다.

E 유형(기획)은 본문·검증 리포트 대신 `## 기획 파일`(트리와 글자 수) → `## 설계 축`(단계별 선택지와 확인 결과) → `## 교차 대조`(모순·수정·원본) → `## 검수`(기획 문서 모드 지적 n건 → 처리 n건) 순.

## D6 파일 위치

| 것 | 위치 |
|---|---|
| 설계서 JSON (G3용) | 작업 폴더 `joestale-work/<슬러그>/design.json` |
| 초고·최종 | 같은 폴더 `draft.txt`, `final.txt` |
| 리포트 JSON | 같은 폴더 `report.json` |
| 독자 기억 장부 (연재·장편) | 작품 폴더 `reader_memory.md`. 연결 독자가 본문에서만 뽑아 쓰고 장마다 이어 붙인다. 작성자가 고쳐 쓰지 않는다 |
| 기획 문서 (E) | `joestale-work/<슬러그>/01_세계관/ 02_인물/ 03_개요/ 04_세부개요/ design.json(planning 블록) 교차_대조.md`. 한국어 파일명 |
| 우리말샘 키 | 환경변수 `OPENDICT_KEY`. 파일·기록에 적지 않음 |

작업 폴더는 사용자 프로젝트 안이 아니라 요청받은 위치 또는 스크래치. 사용자가 경로를 주면 그곳.

## D7 묻는 경우 (유일)

- 입력에 실존 인물·실제 사건이 등장하고 그 인물에 대한 부정적 묘사를 요구할 때.
- 사용자가 준 원문이 3,000자를 넘을 때(분할 방식 확인).
- E 기획의 단계별 설계 축 관문(선택지·추천을 보이고 확인).

그 외는 묻지 않고 가정 표로 대체한다.
