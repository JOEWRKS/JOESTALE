# 결정표 — 회색지대 없애기 (2026-10-29, 사용자 지시 "회색지대 없이 기능 채워줘")

이 표의 값은 사용자가 바꾸기 전까지 고정이다. 스킬은 아래 항목에 대해 **묻지 않는다**. 바꾸고 싶으면 사용자가 이 파일을 고치거나 요청 안에서 지정한다(요청 안의 지정이 우선).

## D1 입력 분류 규칙

| 판별 순서 | 조건 | 유형 |
|---|---|---|
| 1 | 입력에 "써줘/만들어줘/지어줘/작성" 요청어가 있고 본문이 2문장 이하 | D 써줘 |
| 2 | 입력이 서술문 3문장 이상이고 고쳐 달라는 뜻(고쳐/다듬어/바꿔/리라이트)이거나 요청어가 없음 | A 완성 글 |
| 3 | 1인칭 감상·평가어(답답해, 싫다, 좋았다, 짜증)가 핵심이고 2문장 이하 | C 의견 |
| 4 | 그 외 명사구·짧은 상황 설명 | B 아이디어 |

둘 이상 걸리면 번호가 작은 것. 분류 결과는 설계서에 적는다.

## D2 기본값

| 항목 | 기본값 | 근거 |
|---|---|---|
| 언어 | 한국어. 다른 언어 입력은 한국어로 쓰되 원어 고유명사는 유지 | 1차 기획 |
| 분량 (A) | 원문 글자 수의 0.8~2.0배 | 사물·행동 추가로 늘어남 |
| 분량 (B·C) | 400~700자 | 장면 1개 |
| 분량 (D) | 요청에 "단편"이면 1,500~2,500자, "짧게"면 400~700자, 없으면 800~1,200자 | 임의 기본값 |
| 시점 | 3인칭 제한. 입력에 "나/내가"가 있으면 1인칭 | 입력 추론 |
| 시제 | 과거형(~했다) | 작가 예문과 일치 |
| 문체 | 평서문 종결(~다). 경어체 금지 | 작가 예문과 일치 |
| 장르 | 입력에 없으면 일상 사실주의. 판타지·SF 요소를 스스로 넣지 않음 | 상상 과잉 방지 |
| 인물 이름 | 입력에 없으면 성 없는 두 글자 이름 1개를 짓고 가정 표에 적음 | 대장 기준 |
| 문단 | 200~350자마다 나눔. 대화는 줄 바꿈 | R5·R6가 문단 단위 |
| 대화 비율 | 전체의 30% 이하 | 묘사 중심 |
| 소재 낚기 | B·C·D 필수, A는 원문에 사물이 1개도 없을 때만 | SKILL 0단계 |
| 결합 시드 선택 | 후보 3개 중 비시각 감각 키워드 수 → 숫자 포함 여부 → 짧은 것 순으로 선택 | 측정값 기준 |

## D3 임계값

| 규칙 | 값 | 비고 |
|---|---|---|
| R1 정도부사 | 0회 | lexicon.json `degree_adverbs` |
| R2 수식어 비율 | ≤ 0.18 (글 전체), 문장 하나가 ≥ 0.50이면 그 문장도 위반 | 작가 예문 C 0.07~0.18 |
| R3 상태 서술 | 0회 | `state_patterns` |
| R4 감정 직설 | 0회. 대화문("…") 안은 예외 | 인물이 말로는 감정을 말할 수 있음 |
| R5 비시각 감각 | 문단당 ≥ 1 | `senses` 6종 중 아무거나 |
| R6 구체화 | 문단당 (숫자·수관형사·고유명사 ≥ 1) 또는 (일반명사 ≥ 3) | 작가 예문 A·B는 숫자 없이 명사 4·9개로 통과 |
| G1 조사 | 0건 | 받침 규칙 |
| G2 어미 반복 | 마지막 어절 동일 3연속 금지 | "~다" 자체는 세지 않음 |
| G3 대장 | 설계서 대장의 인물·장소·숫자가 본문에 전부 있어야 함. 설계서에 없는 고유명사(NNP)가 본문에 나오면 위반 | 이름 바꿔치기 방지 |
| T1 번역투·AI 관용구 | 패턴별 상한(lexicon.json `translationese[].max`) | 대부분 0~2 |
| T2 문단 첫 어절 반복 | 3문단 연속 동일 금지 | "그는/그녀는" |
| 띄어쓰기 | 보고만. 자동 수정 없음 | ISSUES I-4 |

## D4 실패 시 동작

| 상황 | 동작 |
|---|---|
| 3단계 위반 | 4단계 국소 리라이트, 최대 3회 |
| 3회 후에도 위반 | 멈추고 제출. 리포트 "남은 위반"에 문장과 이유를 적는다. 추가 리라이트는 사용자 요청 시 |
| R2는 통과하나 작가 예문 복제(녹슨 경첩, 세 겹 스티커, 살얼음 등 principles.md 예문의 명사구 그대로) | 위반으로 취급, 바꾼다 |
| 서브에이전트 불가 | 5단계를 같은 맥락에서 하고 리포트에 `검수: DEGRADED(같은 맥락)` 표기 |
| Kiwi 미설치 | 3단계 건너뛰지 않음. `pip install kiwipiepy` 안내 후 중단 |
| 입력이 한국어 작문이 아님(코드·보고서·번역 요청) | 스킬을 쓰지 않는다고 한 줄로 말하고 일반 처리 |

## D5 출력 형식 (고정)

```
## 본문
(글)

## 설계서
유형 / 시드 / 재료 표 / 대장 / 가정 표

## 검증 리포트
| 항목 | 초고 | 최종 |
수식어 비율, 정도부사 수, 감정 직설 수, 조사 오류, 어미 반복, 번역투 건수
남은 위반: (없음 또는 목록과 이유)
검수: PASS / DEGRADED / 지적 n건 → 처리 n건
```

A 유형(리라이트)은 본문 앞에 "원문" 절을 추가한다.

## D6 파일 위치

| 것 | 위치 |
|---|---|
| 설계서 JSON (G3용) | 작업 폴더 `joestale-work/<슬러그>/design.json` |
| 초고·최종 | 같은 폴더 `draft.txt`, `final.txt` |
| 리포트 JSON | 같은 폴더 `report.json` |
| 우리말샘 키 | 환경변수 `OPENDICT_KEY`. 파일·기록에 적지 않음 |

작업 폴더는 사용자 프로젝트 안이 아니라 요청받은 위치 또는 스크래치. 사용자가 경로를 주면 그곳.

## D7 묻는 경우 (유일)

- 입력에 실존 인물·실제 사건이 등장하고 그 인물에 대한 부정적 묘사를 요구할 때.
- 사용자가 준 원문이 3,000자를 넘을 때(분할 방식 확인).

그 외는 묻지 않고 가정 표로 대체한다.
