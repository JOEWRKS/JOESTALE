## 사는 방식

- 초소 근무: 밤 10시 인수 ~ 아침 6시 교대(1, 3, 4, 7, 8장). 6장에 "217 야간 조". 주 단위로 근무 시간대가 바뀐다는 설명은 본문에 없음. 8장 "마지막 야간 근무", 10장 "저녁 근무"가 전부.
- 근무 시작 때 버너를 쓰는 10분. 태석이 컨테이너 문턱 안쪽에서 고형연료 버너를 코펠 밑에 밀어 넣음. 불린 쌀로 쌀죽. 세 몫: 알루미늄 컵 하나, 뚜껑 하나(민규), 코펠 하나(도현).
- 투시경 2시간에 한 번 한 바퀴. AA 배터리가 모자람. 무전기 몫은 월 8개, 매시 정각 교신만. 사격 보고는 즉시.
- 교전선 50m 표지판, T-박스. 탄 60발. 쏜 탄피는 전부 회수, 아침 보고. 월 10발 넘으면 면담.
- 손님은 0도 아래에서 걸음이 절반. 총성이 길면 모여듦.
- 접종 순서: 진입조 → 격리반 → 초소 지정 사수. 맞으면 배급 가산(1회차 맞은 날부터), 하루 3,500kcal.
- 암시장: AA 한 개 3만 원, 바이알 약 2,000만 원, 가짜 10건에 7건.
